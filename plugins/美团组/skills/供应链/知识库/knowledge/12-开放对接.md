## 🎯 模块概述

### 功能定位

**开放对接**模块是美团供应链管理系统的**API集成中枢**,提供标准化接口让第三方系统与美团SCM系统进行数据交互。

**核心价值**:
- **系统互联**: 打通美团SCM与ERP、WMS、TMS等外部系统
- **数据同步**: 实时双向同步订单、库存、物品等核心数据
- **流程自动化**: 通过API自动触发业务流程,减少人工操作
- **生态整合**: 接入美团生态服务(支付、物流、营销)

### 业务场景

1. **ERP系统对接**: 将美团SCM订单同步到企业ERP进行财务核算
2. **WMS仓储对接**: 实时同步库存数据,优化仓储管理
3. **第三方配送对接**: 接入外部物流系统,扩展配送能力
4. **BI数据分析对接**: 导出经营数据到数据仓库进行深度分析
5. **供应商协同对接**: 供应商系统直连,实现订单自动接收与确认

## 🔧 核心功能详解

### 1. API认证与授权

#### 1.1 认证方式

| 认证类型 | 适用场景 | 安全级别 |
|---------|---------|---------|
| **AppKey + AppSecret** | 服务端调用 | 高 |
| **OAuth 2.0** | 第三方应用授权 | 高 |
| **API Token** | 临时访问 | 中 |
| **IP白名单** | 固定服务器调用 | 高 |

#### 1.2 鉴权流程

```
步骤1: 获取AppKey和AppSecret
  → 在【认证管理】模块申请应用凭证

步骤2: 生成访问令牌(Access Token)
  → POST /open-api/auth/token
  → 请求体: { appKey, appSecret, timestamp, sign }
  → 响应: { accessToken, expiresIn }

步骤3: 调用业务API
  → Header: Authorization: Bearer {accessToken}
  → 每次请求携带token进行身份验证

步骤4: Token续期
  → Token有效期通常为2小时
  → 过期前通过refresh_token刷新
```

### 4. 第三方系统集成

#### 4.1 ERP系统对接

**集成场景**:
1. **财务核算**: 每日自动导出配送单到财务系统
2. **应付账款**: 采购收货单同步到应付模块
3. **成本核算**: 盘点结果同步到成本会计

**数据流向**:
```
美团SCM → ERP:
  - 配送单(已发货)
  - 采购收货单
  - 盘点单
  - 库存余额

ERP → 美团SCM:
  - 物品主数据
  - 供应商主数据
  - 成本价格调整
```

#### 4.2 WMS系统对接

**集成场景**:
1. **入库管理**: 采购收货单自动创建WMS入库单
2. **出库管理**: 配送单自动生成WMS拣货任务
3. **库存同步**: WMS库存实时回写到美团SCM

**接口清单**:
- `POST /wms-api/inbound/create` - 创建入库单
- `POST /wms-api/outbound/create` - 创建出库单
- `POST /wms-api/inventory/sync` - 同步库存数据

#### 4.3 TMS物流对接

**集成场景**:
1. **运单创建**: 配送单自动创建物流运单
2. **配送跟踪**: 实时获取物流状态更新
3. **签收回传**: 门店签收后回写到美团SCM

## 🔒 安全最佳实践

### 1. 凭证管理

- ✅ **AppSecret加密存储**: 使用环境变量或密钥管理服务
- ✅ **定期轮换**: 每90天更换一次AppSecret
- ✅ **最小权限原则**: 只申请必要的API权限
- ❌ **禁止硬编码**: 不要在代码中硬编码密钥

### 2. 网络安全

- ✅ **HTTPS传输**: 所有API调用必须使用HTTPS
- ✅ **IP白名单**: 限制API调用来源IP
- ✅ **请求签名**: 使用HMAC-SHA256签名验证请求
- ✅ **防重放攻击**: 使用timestamp + nonce机制

### 3. 数据安全

- ✅ **敏感数据加密**: 价格、金额等敏感字段加密传输
- ✅ **日志脱敏**: API调用日志中隐藏敏感信息
- ✅ **数据备份**: 定期备份关键业务数据
- ✅ **访问审计**: 记录所有API调用的操作日志

## 🚀 快速开始示例

### Python调用示例

```python
import requests
import hashlib
import time
import json

class MeituanSCMClient:
    def __init__(self, app_key, app_secret, base_url):
        self.app_key = app_key
        self.app_secret = app_secret
        self.base_url = base_url
        self.access_token = None

    def get_access_token(self):
        """获取访问令牌"""
        timestamp = int(time.time())
        sign_str = f"{self.app_key}{timestamp}{self.app_secret}"
        sign = hashlib.sha256(sign_str.encode()).hexdigest()

        payload = {
            "appKey": self.app_key,
            "timestamp": timestamp,
            "sign": sign
        }

        response = requests.post(
            f"{self.base_url}/open-api/auth/token",
            json=payload
        )

        if response.status_code == 200:
            data = response.json()
            self.access_token = data["data"]["accessToken"]
            return self.access_token
        else:
            raise Exception(f"获取Token失败: {response.text}")

    def query_inventory(self, warehouse_code, item_codes):
        """查询库存"""
        if not self.access_token:
            self.get_access_token()

        headers = {
            "Authorization": f"Bearer {self.access_token}",
            "Content-Type": "application/json"
        }

        params = {
            "warehouseCode": warehouse_code,
            "itemCodes": ",".join(item_codes)
        }

        response = requests.get(
            f"{self.base_url}/open-api/inventory/query",
            headers=headers,
            params=params
        )

        return response.json()

# 使用示例

    app_key="your_app_key",
    app_secret="your_app_secret",
    base_url="https://pos.meituan.com"
```
