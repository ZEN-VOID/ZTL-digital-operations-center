# 美团管家供应链系统 - 总览文档

> **研究时间**: 2025-11-03
> **研究对象**: 美团管家供应链版块 (https://pos.meituan.com/web/web-scm/scm-home)
> **研究目的**: 全面了解供应链系统功能架构和业务流程

## 一、系统定位

美团管家供应链系统是面向餐饮连锁企业的一体化供应链管理平台,支持总部-配送中心-门店三级架构,覆盖采购、配送、库存、生产、财务等全链路业务。

### 核心价值
- **集中管控**: 总部统一管理物品档案、供应商、价格体系
- **多级协同**: 支持总部→配送中心→门店的多级配送体系
- **业务闭环**: 从采购到配送到库存的完整业务闭环
- **数据驱动**: 实时库存、成本分析、经营报表支持决策

### 系统架构
```
总部(集团)
    ├── 配送中心1
    │   ├── 门店A
    │   ├── 门店B
    │   └── 门店C
    ├── 配送中心2
    │   ├── 门店D
    │   └── 门店E
    └── ...
```

## 二、功能模块架构

### 2.1 核心业务模块

#### 1. 配送管理 (Delivery Management)
**模块标识**: `#menucode_1887`
**核心定位**: 处理配送中心→门店的订货和配送流程

**关键功能推断**:
- 门店订货单管理
- 配送单生成与发货
- 配送价格管理
- 配送范围设置
- 配送方式配置(支持4种配送方式)
- 配送差异处理
- 配送返货管理

**业务流程**:
```
门店发起订货 → 配送中心审核 → 拣货打包 → 发货配送 → 门店收货确认
```

## 三、核心业务流程

### 3.1 采购流程
```
【档案管理】创建供应商
    ↓
【采购管理】设置采购定价
    ↓
【采购管理】创建采购订单
    ↓
供应商发货
    ↓
【采购管理】采购收货单验收
    ↓
【库存管理】入库
    ↓
【财务管理】供应商对账付款
```

### 3.2 配送流程
```
【档案管理】设置物品档案
    ↓
【配送管理】设置配送价格
    ↓
【配送管理】设置配送范围
    ↓
【配送管理】门店发起订货单
    ↓
【配送管理】配送中心审核
    ↓
【库存管理】配送中心出库
    ↓
【配送管理】生成配送单、发货
    ↓
【配送管理】门店收货确认
    ↓
【配送管理】处理配送差异(如有)
    ↓
【财务管理】门店对账结算
```

### 3.3 盘点流程
```
【库存管理】创建盘点单
    ↓
【库存管理】执行盘点(录入实盘数量)
    ↓
【库存管理】盘点差异分析
    ↓
【库存管理】盘点单审核
    ↓
【库存管理】账面库存调整
    ↓
【财务管理】盘盈盘亏财务处理
```

### 3.4 生产流程
```
【档案管理】维护BOM(物料清单)
    ↓
【生产管理】创建生产计划
    ↓
【生产管理】生成生产工单
    ↓
【生产管理】生产领料(原料出库)
    ↓
【生产管理】生产加工
    ↓
【生产管理】生产报工
    ↓
【生产管理】成品入库
    ↓
【财务管理】生产成本核算
```

## 五、关键业务实体

### 5.1 单据体系

| 单据类型 | 所属模块 | 业务场景 | 关键字段 |
|---------|---------|---------|---------|
| 门店订货单 | 配送管理 | 门店向配送中心订货 | 订货门店、订货日期、物品清单、订货数量 |
| 配送单 | 配送管理 | 配送中心向门店配送 | 配送中心、目标门店、配送日期、配送物品、配送数量 |
| 采购订单 | 采购管理 | 向供应商采购 | 供应商、采购日期、物品清单、采购数量、采购单价 |
| 采购收货单 | 采购管理 | 采购入库验收 | 采购订单、收货日期、收货数量、质检结果 |
| 盘点单 | 库存管理 | 库存盘点 | 盘点日期、盘点仓库、账面数量、实盘数量、盘点差异 |
| 销售订单 | 销售管理 | 对外销售 | 客户、销售日期、物品清单、销售数量、销售单价 |
| 生产工单 | 生产管理 | 生产加工 | 生产日期、产品、生产数量、原料消耗、成品产出 |
| 调拨单 | 库存管理 | 仓库间调拨 | 调出仓库、调入仓库、调拨物品、调拨数量 |
| 报损单 | 库存管理 | 库存报损 | 报损日期、报损仓库、报损物品、报损数量、报损原因 |

### 5.2 主数据实体

| 实体名称 | 所属模块 | 核心属性 | 业务用途 |
|---------|---------|---------|---------|
| 物品档案 | 档案管理 | 物品编码、物品名称、规格、单位、类别 | SKU主数据,全系统通用 |
| 成本卡 | 档案管理 | 成本卡编码、关联菜品、关联物品、用量 | 菜品成本核算 |
| 供应商档案 | 档案管理 | 供应商编码、名称、联系方式、供货范围 | 采购管理 |
| 客户档案 | 档案管理 | 客户编码、名称、联系方式、信用额度 | 销售管理 |
| 仓库档案 | 档案管理 | 仓库编码、仓库名称、仓库类型、所属组织 | 库存管理 |
| 配送中心 | 系统设置 | 中心编码、名称、地址、负责区域 | 组织架构 |
| 门店档案 | 系统设置 | 门店编码、名称、地址、所属配送中心 | 组织架构 |

## 九、典型应用场景

### 场景1: 连锁火锅店供应链管理
**组织架构**: 1个总部 + 3个配送中心 + 50家门店

**业务流程**:
1. 总部统一采购牛羊肉等核心食材
2. 配送中心负责本区域门店配送
3. 门店每日订货,配送中心次日配送
4. 月末统一对账结算

### 场景2: 中央厨房+门店模式
**组织架构**: 1个中央厨房 + 20家门店

**业务流程**:
1. 中央厨房采购原料
2. 生产加工半成品/成品
3. 配送至门店
4. 成本核算(原料成本+加工成本)

### 场景3: 多品牌连锁管理
**组织架构**: 1个集团总部 + 3个品牌 + 各自的配送中心和门店

**业务流程**:
1. 集团层面统一物品档案
2. 各品牌独立价格体系
3. 共享配送中心(可选)
4. 集团层面财务合并
