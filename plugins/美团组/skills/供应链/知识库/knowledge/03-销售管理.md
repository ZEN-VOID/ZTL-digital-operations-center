# 03-销售管理 (Sales Management)

## 模块概述

### 模块定位
销售管理模块是美团供应链管理系统中的核心业务模块,负责从销售订单创建、审批、执行到结算的全流程管理。该模块与配送管理、库存管理、财务管理等模块深度集成,确保销售业务的顺畅运行。

### 核心功能
- 销售订单全生命周期管理
- 销售出库单据处理
- 销售退货管理
- 销售结算与对账
- 销售数据分析与报表
- 客户信用管理
- 价格策略与促销管理

### 与其他模块的关联
```
销售管理
├── → 库存管理: 触发库存扣减,生成出库单
├── → 配送管理: 创建配送任务,安排物流
├── → 财务管理: 生成应收账款,财务结算
├── → 档案管理: 调用客户档案、商品档案
├── ← 采购管理: 根据销售预测触发采购需求
└── → 报表管理: 提供销售数据源,生成分析报表
```

##### 业务规则
1. **订单状态流转**:
   - 待审批 → 审批通过 → 已审批
   - 待审批 → 审批拒绝 → 已取消
   - 已审批 → 生成出库单 → 执行中
   - 执行中 → 全部出库 → 已完成
   - 任何状态 → 取消操作 → 已取消

2. **权限控制**:
   - 销售员:可创建订单、查看自己的订单
   - 销售主管:可审批订单、查看所有订单
   - 仓库管理员:可查看已审批订单、生成出库单
   - 财务人员:可查看所有订单、导出数据

3. **数据关联**:
   - 订单创建时,自动关联客户档案信息
   - 订单审批后,自动锁定库存
   - 生成出库单后,订单状态变为"执行中"
   - 出库单完成后,订单状态变为"已完成"

4. **计算逻辑**:
   - 订单金额 = Σ(商品单价 × 数量 - 优惠金额) + 配送费
   - 商品总数 = 订单中不同SKU的数量
   - 应收金额 = 订单金额 - 已付款金额

##### 费用汇总区域
- **商品金额**: Σ(数量 × 单价 × (1 - 折扣率/100))
- **优惠金额**: 用户输入的优惠金额
- **配送费**: 用户输入的配送费
- **订单总额**: 商品金额 - 优惠金额 + 配送费

##### 业务规则
1. **客户信用检查**:
   - 选择客户后,自动检查客户信用额度
   - 如果订单金额 + 客户应收款 > 信用额度,弹出警告提示
   - 超信用额度的订单需要特殊审批

2. **商品库存检查**:
   - 添加商品时,自动检查可用库存
   - 如果数量 > 可用库存,显示警告图标
   - 库存不足的订单可以创建,但需要备注

3. **价格策略**:
   - 商品单价自动从客户价格表获取
   - 如果客户无专属价格,使用商品标准价格
   - 单价可以手动修改,但需要权限

4. **优惠规则**:
   - 折扣优惠:按百分比计算,如9折=10%优惠
   - 满减优惠:订单金额满X元减Y元
   - 固定优惠:直接减免固定金额
   - 优惠金额不能超过商品金额

5. **自动计算**:
   - 商品行小计 = 数量 × 单价 × (1 - 折扣率/100)
   - 商品金额 = Σ(商品行小计)
   - 订单总额 = 商品金额 - 优惠金额 + 配送费
   - 实时更新,自动计算

   - 编辑后需要重新提交审批
   - 已审批或执行中的订单不可编辑

3. **审批规则**:
   - 订单金额 < 10,000元:销售主管审批
   - 订单金额 ≥ 10,000元:销售总监审批
   - 超信用额度订单:需要财务经理审批

##### 业务规则

   - 待审批 → 审批拒绝 → 已取消
   - 已审批 → 开始拣货 → 执行中
   - 执行中 → 全部出库 → 已完成
   - 执行中 → 部分出库 → 执行中

   - 待审批 → 审批拒绝 → 已取消
   - 已审批 → 开始验货 → 执行中
   - 执行中 → 全部入库 → 已完成
   - 执行中 → 部分入库 → 执行中

2. **权限控制**:
   - 销售员:可创建退货单、查看自己创建的退货单
   - 仓库管理员:可审批、执行退货入库
   - 财务人员:可查看所有退货单、生成退款单

3. **退货原因分类**:
   - 质量问题:商品质量不合格,需要质量检验
   - 发错货:发货错误,需要换货
   - 客户原因:客户自身原因退货,可能收取退货费
   - 其他:其他特殊原因

4. **退款计算**:
   - 退款金额 = Σ(退货商品单价 × 退货数量)
   - 如果是客户原因退货,可能扣除一定比例的退货费
   - 如果是质量问题,全额退款且可能包含补偿

```
销售业务数据流:

客户下单
  ↓

  ↓

  ↓

  ↓

  ↓
收款 → 释放信用额度(剩余)
  ↓
结算完成

退货业务数据流:

客户申请退货
  ↓
创建退货单 → 关联原订单
  ↓
退货单审批
  ↓
执行退货入库 → 增加库存
  ↓
生成退款单(财务管理模块)
  ↓
退款 → 释放信用额度
  ↓
退货完成
```

## 自动化要点

### 自动化场景

1. **订单自动审批**:
   - 场景:订单金额 < 5,000元且客户信用正常
   - 触发条件:订单提交审批
   - 自动操作:系统自动审批通过
   - CSS选择器:`.btn-submit`(提交审批按钮)

2. **自动生成出库单**:
   - 场景:订单审批通过后
   - 触发条件:订单状态变为"已审批"
   - 自动操作:自动生成出库单
   - CSS选择器:`.btn-create-outbound`(生成出库单按钮)

3. **库存预警**:
   - 场景:出库后库存低于安全库存
   - 触发条件:库存扣减后
   - 自动操作:发送预警消息、生成采购需求
   - CSS选择器:无(后台自动触发)

4. **信用额度预警**:
   - 场景:客户信用额度使用率 > 80%
   - 触发条件:订单创建、收款
   - 自动操作:发送预警消息给销售员和财务
   - CSS选择器:无(后台自动触发)

5. **价格自动匹配**:
   - 场景:创建订单时,自动匹配客户价格
   - 触发条件:选择客户和商品
   - 自动操作:自动填充商品单价
   - CSS选择器:`select[name="customerId"]`, `select[name="productId"]`

6. **促销自动应用**:
   - 场景:订单满足促销条件
   - 触发条件:商品金额计算完成
   - 自动操作:自动应用最优促销活动
   - CSS选择器:无(前端自动计算)

7. **结算单自动生成**:
   - 场景:每月1日自动生成上月结算单
   - 触发条件:定时任务
   - 自动操作:为所有客户生成上月结算单
   - CSS选择器:无(后台定时任务)

## 注意事项

### 权限要求

1. **销售员权限**:
   - 可创建销售订单
   - 可查看自己创建的订单
   - 可查看关联的出库单、退货单
   - 不可审批订单
   - 不可查看其他销售员的订单

2. **销售主管权限**:
   - 拥有销售员的所有权限
   - 可审批订单(金额 < 10,000元)
   - 可查看所有订单
   - 可设置客户价格(需审批)
   - 可创建促销活动(需审批)

3. **销售总监权限**:
   - 拥有销售主管的所有权限
   - 可审批所有金额订单
   - 可审批价格调整
   - 可审批促销活动
   - 可查看所有销售数据

4. **仓库管理员权限**:
   - 可查看已审批的订单
   - 可创建、审批、执行出库单
   - 可处理退货入库
   - 不可修改订单
   - 不可查看销售数据

5. **财务人员权限**:
   - 可查看所有订单、出库单、退货单
   - 可创建结算单
   - 可登记收款
   - 可设置客户信用额度
   - 可查看销售分析报表
   - 不可修改订单
   - 不可审批订单

### 数据依赖

1. **客户档案依赖**:
   - 创建订单前必须有客户档案
   - 客户信息从档案管理模块同步
   - 客户类别、联系方式等依赖档案数据

2. **商品档案依赖**:
   - 创建订单前必须有商品档案
   - 商品信息从档案管理模块同步
   - 商品价格、规格等依赖档案数据

3. **库存数据依赖**:
   - 出库单创建时需要查询库存
   - 出库执行时需要扣减库存
   - 退货入库时需要增加库存
   - 库存数据与库存管理模块实时同步

4. **财务数据依赖**:
   - 结算单生成时需要查询应收账款
   - 收款登记需要更新财务数据
   - 财务数据与财务管理模块实时同步

5. **配送数据依赖**:
   - 出库单完成后生成配送任务
   - 配送状态影响订单状态
   - 配送数据与配送管理模块实时同步

### 特殊限制

1. **订单修改限制**:
   - 已审批的订单不可修改
   - 执行中的订单不可取消
   - 已完成的订单不可删除

2. **出库限制**:
   - 未审批的订单不能生成出库单
   - 库存不足的商品不能执行出库
   - 出库数量不能超过订单数量

3. **退货限制**:
   - 未出库的订单不能退货
   - 退货数量不能超过出库数量
   - 超过退货时效的订单需要特殊审批

4. **价格限制**:
   - 客户价格不能低于成本价
   - 价格下调超过20%需要总监审批
   - 促销价格不能低于成本价

5. **信用限制**:
   - 超信用额度的订单需要财务审批
   - 信用冻结的客户不能创建订单
   - 信用额度调整需要审批

6. **促销限制**:
   - 一个订单只能使用一个促销活动
   - 促销活动不能重叠
   - 进行中的活动不能修改

7. **结算限制**:
   - 未完成的订单不能结算
   - 结算周期内必须有订单
   - 结算金额必须与订单金额一致
