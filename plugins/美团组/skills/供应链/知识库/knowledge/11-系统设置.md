## 1️⃣ 模块概述

### 1.1 功能定位

系统设置模块是美团供应链管理系统的**底层支撑和管理中枢**,承担以下核心职责:

- **系统参数配置**: 成本计价方式、会计期间、单据编号规则等全局参数
- **权限管理**: 用户角色、权限分配、数据权限控制、操作审计
- **基础档案维护**: 组织架构、部门、仓库、门店等基础数据
- **业务流程配置**: 审批流程、单据流转规则、业务关系配置
- **系统集成**: API接口配置、第三方对接、数据同步规则
- **数据管理**: 数据备份、归档、清理、导入导出

### 1.2 核心价值

| 价值维度 | 具体体现 |
|---------|----------|
| **标准化** | 统一全系统的数据标准、编码规则、业务流程 |
| **安全性** | 精细化权限控制、操作审计、数据备份 |
| **灵活性** | 可配置的业务规则、参数化系统行为 |
| **集成性** | 支持多系统对接、数据互通、流程协同 |
| **可维护性** | 基础数据集中管理、版本控制、变更追溯 |

### 1.3 模块间关系


## 3️⃣ 功能域1: 系统参数配置

### 3.1 成本计价设置 (#menucode_1975_01_01)

#### 核心功能
配置全系统的成本计价方法,支持加权平均、移动加权平均、先进先出等多种计价模式。

#### 关键字段(推断)

| 字段名称 | 字段类型 | 是否必填 | 说明 |
|---------|---------|----------|------|
| 计价方法 | 下拉选择 | 是 | 加权平均、移动加权、先进先出、后进先出 |
| 适用范围 | 多选 | 是 | 可选:原材料、半成品、成品、低值易耗品 |
| 生效日期 | 日期 | 是 | 参数生效的会计期间起始日期 |
| 启用状态 | 开关 | 是 | 启用/停用 |
| 变更审批 | 开关 | 否 | 是否需要审批才能变更计价方法 |

#### 业务规则

1. **计价方法变更限制**: 当前会计期间已有业务单据时,禁止变更计价方法
2. **历史数据兼容**: 变更计价方法后,已关账期间的数据不重算
3. **多仓库独立配置**: 支持不同仓库使用不同计价方法
4. **审计追踪**: 所有参数变更记录操作人、时间、变更前后值

### 3.2 会计期间配置 (#menucode_1975_01_02)

#### 核心功能
管理财务会计期间的开启、关闭、结转,确保成本核算的时间准确性。

#### 关键字段(推断)

| 字段名称 | 字段类型 | 必填 | 说明 |
|---------|---------|------|------|
| 会计年度 | 年份选择 | 是 | 例:2025 |
| 会计期间 | 月份选择 | 是 | 1-12月,或自定义周期 |
| 期间状态 | 状态标签 | - | 未开启、已开启、已关账 |
| 关账日期 | 日期 | 否 | 期间关闭的时间 |
| 允许反关账 | 开关 | 否 | 是否允许重新打开已关账期间 |

#### 业务规则

1. **顺序关账**: 必须按时间顺序关闭会计期间,不能跳期关账
2. **反关账权限**: 反关账需要超级管理员权限审批
3. **期间锁定**: 关账后,该期间的所有单据禁止新增、编辑、删除
4. **自动期间**: 系统自动创建下一会计期间(可配置)

### 3.3 单据编号规则 (#menucode_1975_01_03)

#### 核心功能
配置各类业务单据的自动编号规则,确保单据唯一性和可追溯性。

#### 编号规则模板(推断)

| 单据类型 | 编号规则示例 | 说明 |
|---------|------------|------|
| 采购订单 | PO{YYYY}{MM}{DD}{SEQ4} | PO20250103001 |
| 入库单 | IN{SHOP_CODE}{SEQ6} | IN0001000001 |
| 出库单 | OUT{DEPT_CODE}{YYYY}{SEQ5} | OUTKT202500001 |
| 调拨单 | TR{YYYY}{MM}{SEQ5} | TR20250100001 |
| 盘点单 | INV{YYYY}{MM}{DD}{SEQ3} | INV20250103001 |

#### 编号变量说明

| 变量 | 含义 | 示例 |
|------|------|------|
| {YYYY} | 四位年份 | 2025 |
| {MM} | 两位月份 | 01 |
| {DD} | 两位日期 | 03 |
| {SEQ4} | 四位流水号 | 0001 |
| {SHOP_CODE} | 门店编码 | 0001 |

## 4️⃣ 功能域2: 权限管理

### 4.1 角色管理 (#menucode_1975_02_01)

#### 核心功能
定义系统角色,配置角色权限,实现基于角色的访问控制(RBAC)。

#### 预置角色(推断)

| 角色名称 | 角色编码 | 权限范围 | 数据范围 |
|---------|---------|---------|---------|
| 超级管理员 | SUPER_ADMIN | 全部功能 | 全部数据 |
| 供应链管理员 | SCM_ADMIN | 供应链模块全部功能 | 全公司数据 |
| 采购员 | PURCHASER | 采购订单、供应商管理 | 所属部门数据 |
| 仓库管理员 | WAREHOUSE_MGR | 入库、出库、盘点 | 所属仓库数据 |
| 门店经理 | STORE_MGR | 库存查询、领料申请 | 所属门店数据 |
| 财务 | FINANCE | 成本核算、财务报表 | 授权门店数据 |

#### 权限配置矩阵(示例)

| 功能模块 | 查看 | 新增 | 编辑 | 删除 | 审批 | 导出 |
|---------|-----|------|------|------|------|------|
| 采购订单 | ✓ | ✓ | ✓ | ✓ | - | ✓ |
| 入库单 | ✓ | ✓ | ✓ | - | - | ✓ |
| 成本报表 | ✓ | - | - | - | - | ✓ |

### 4.2 数据权限配置 (#menucode_1975_02_03)

#### 核心功能
配置用户的数据访问范围,实现数据行级权限控制。

#### 数据权限维度(推断)

| 维度 | 配置方式 | 示例 |
|------|---------|------|
| 组织维度 | 选择可见组织/部门 | 仅查看华北大区数据 |
| 仓库维度 | 选择可见仓库 | 仅查看北京仓数据 |
| 门店维度 | 选择可见门店 | 仅查看自己负责的10家店 |
| 供应商维度 | 选择可见供应商 | 仅查看合作供应商 |
| 单据维度 | 按创建人/部门过滤 | 仅查看自己创建的单据 |

#### 业务规则

1. **最小授权原则**: 默认无权限,按需授权
2. **权限继承**: 子组织继承父组织的权限配置
3. **权限冲突**: 明确授权优先于继承权限
4. **审计日志**: 记录所有权限变更操作

|------|------|------|------|

| 仓库编码 | 文本 | 是 | 唯一编码,例:BJ_CK_001 |

## 6️⃣ 功能域4: 流程配置

### 6.1 审批流程设置 (#menucode_1975_04_01)

#### 核心功能
配置各类业务单据的审批流程,支持多级审批、会签、或签。

#### 审批流程模板(推断)

| 单据类型 | 审批流程 | 触发条件 |
|---------|---------|---------|
| 采购订单 | 采购员 → 采购主管 → 部门经理 | 金额>5000元 |
| 采购订单 | 采购员 → 采购主管 | 金额≤5000元 |
| 入库单 | 仓库管理员 → 仓库主管 | 无条件 |
| 调拨单 | 发起人 → 调出仓主管 → 调入仓主管 | 跨大区调拨 |
| 盘点单 | 盘点人 → 仓库主管 → 财务 | 盘盈盘亏>1万元 |

#### 审批节点配置

| 节点属性 | 配置项 | 说明 |
|---------|-------|------|
| 审批人 | 指定用户/角色/部门负责人/上级主管 | 动态确定审批人 |
| 审批方式 | 单人/会签(全部同意)/或签(一人同意即可) | 多人审批时的逻辑 |
| 审批期限 | 小时数 | 超期自动提醒或升级 |
| 拒绝规则 | 退回发起人/退回上一节点/直接拒绝 | 审批拒绝后的处理 |

#### Chrome-MCP 操作流程(推断)

```javascript
// 审批流程配置操作步骤
async function configApprovalFlow(page) {
  // 1. 进入审批流程配置页面
  await page.click('#menucode_1975_04_01');

  // 2. 选择单据类型
  await page.selectOption('select[name="documentType"]', 'PURCHASE_ORDER');

  // 3. 配置审批节点
  await page.click('button.add-approval-node');
  await page.selectOption('select[name="approverType"]', 'ROLE');
  await page.selectOption('select[name="approverRole"]', 'PURCHASE_SUPERVISOR');

  // 4. 设置审批条件
  await page.fill('input[name="amountThreshold"]', '5000');

  // 5. 保存配置
  await page.click('button.save-flow');
}
```

### 6.2 单据流转规则 (#menucode_1975_04_02)

#### 核心功能
配置单据的状态流转规则、自动流转条件、异常处理机制。

#### 单据状态机(以采购订单为例)

```
[草稿] ──提交──> [待审批] ──审批通过──> [已审批] ──入库完成──> [已完成]
  │                │                         │
  └───删除────> [已删除]    审批拒绝──> [已拒绝]  取消──> [已取消]
                            │
                            └───重新提交──> [待审批]
```

#### 自动流转规则(推断)

| 触发事件 | 流转动作 | 业务规则 |
|---------|---------|---------|
| 采购订单审批通过 | 自动生成待收货任务 | 推送通知仓库管理员 |
| 入库单保存 | 自动关联采购订单 | 按订单号自动匹配 |
| 入库单提交 | 自动增加库存 | 实时更新可用库存 |
| 盘点单审批通过 | 自动调整库存 | 生成库存调整单 |
| 调拨单审批通过 | 锁定调出仓库存 | 预留出库数量 |

### 7.2 数据同步规则 (#menucode_1975_05_03)

#### 核心功能

#### 数据同步场景(推断)

| 同步场景 | 同步方向 | 同步频率 | 数据内容 |
|---------|---------|---------|---------|
| 门店信息 | 餐饮系统 → SCM | 每日凌晨1点 | 门店基本信息、营业状态 |
| 组织架构 | 美团开放平台 → SCM | 实时同步 | 组织架构变更、人员变动 |
| 库存数据 | SCM → 餐饮系统 | 每15分钟 | 各门店原材料库存余额 |
| 采购订单 | SCM → 供应商系统 | 实时推送 | 审批通过的采购订单 |
| 入库单 | 供应商系统 → SCM | 实时接收 | 供应商发货单、物流信息 |

#### 同步失败处理

| 失败场景 | 处理策略 | 告警机制 |
|---------|---------|---------|
| 网络超时 | 自动重试3次,间隔5分钟 | 3次失败后发送告警 |
| 数据格式错误 | 记录错误日志,跳过当前数据 | 实时告警 |
| 业务校验失败 | 记录业务日志,进入异常队列 | 每日汇总告警 |
| API限流 | 延迟1分钟后重试 | 无需告警 |

## 1️⃣2️⃣ 业务规则总结

### 12.1 系统参数管理规则

1. **变更控制**: 关键参数(成本计价方法、会计期间)变更需要二次审批
2. **生效机制**: 参数变更支持即时生效或指定日期生效
3. **历史追溯**: 所有参数变更记录操作人、时间、变更前后值,不可删除
4. **影响范围**: 参数变更前系统自动评估影响范围,提示风险

### 12.2 权限管理规则

1. **最小权限原则**: 默认无权限,按需授权,定期审计
2. **权限继承**: 子组织继承父组织权限,可覆盖
3. **角色互斥**: 支持配置互斥角色(如采购员和审批人不能是同一人)
4. **敏感操作**: 删除、关账、参数变更等敏感操作需要额外审批

### 12.3 基础档案管理规则

1. **编码唯一性**: 组织编码、仓库编码、门店编码全系统唯一
2. **停用控制**: 已关联业务数据的档案不可直接停用,需先转移数据
3. **层级限制**: 组织架构最多支持6级,防止层级过深影响性能
4. **数据同步**: 基础档案变更自动同步到美团开放平台

### 12.4 流程配置规则

1. **审批路径**: 不允许出现审批环路,系统自动检测
2. **审批权限**: 审批人必须有该单据类型的审批权限
3. **超期处理**: 审批超期自动升级到上级主管
4. **紧急流程**: 支持配置紧急审批通道(跳过部分节点)
