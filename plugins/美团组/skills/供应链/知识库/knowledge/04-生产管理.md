# 04-生产管理 (Production Management) - 详细文档

## 模块概述

### 定位与价值
生产管理模块是美团管家供应链系统的**核心生产执行引擎**,连接**档案管理**(配方/BOM)与**库存管理**(原料消耗/成品入库),实现从**配方设计→生产计划→工单执行→成品入库**的全流程闭环管理。

### 核心功能
1. **配方管理**: BOM配置、成本核算、配方版本控制
2. **生产计划**: 需求预测、主计划排程、物料需求计算
3. **生产工单**: 工单下达、执行监控、进度追踪
4. **生产执行**: 领料、生产、质检、入库
5. **委外加工**: 委外订单、供应商协同、外协结算
6. **生产报表**: 效率分析、成本分析、异常分析

### 与其他模块的关系
```
┌─────────────┐         ┌─────────────┐         ┌─────────────┐
│ 09-档案管理 │────────>│ 04-生产管理 │────────>│ 05-库存管理 │
│ (配方BOM)  │         │ (生产执行)  │         │ (成品入库)  │
└─────────────┘         └─────────────┘         └─────────────┘
                              │
                              v
                        ┌─────────────┐
                        │ 06-财务管理 │
                        │ (成本核算)  │
                        └─────────────┘
```

- **上游**: 从档案管理获取产品配方、原料清单
- **下游**: 向库存管理推送原料消耗、成品入库
- **关联**: 向财务管理提供生产成本、损耗数据

1. **配方状态流转**:
   - 草稿 → 启用 → 停用
   - 启用状态的配方可直接用于生产工单
   - 停用状态的配方不可用于新工单

2. **版本控制**:
   - 同一产品可有多个配方版本
   - 只能有一个版本处于"启用"状态
   - 版本号自动递增(V1.0 → V2.0 → V3.0)
   - 历史版本保留,支持回溯查询

3. **数据校验**:
   - 产出数量必须 > 0
   - 配方至少包含1种原料
   - 原料总成本自动计算
   - 生产工时必须 ≥ 0

4. **权限控制**:
   - 普通用户只能查看和创建草稿
   - 生产主管可启用/停用配方
   - 系统管理员可删除配方

##### 业务规则

1. **产品选择**:
   - 只能选择"档案管理-产品档案"中的成品
   - 同一产品的不同版本共存,但只有一个版本可启用

2. **原料清单**:
   - 至少包含1种原料
   - 同一配方中原料不能重复
   - 损耗率默认0%, 范围0-100%
   - 实际用量 = 用量 × (1 + 损耗率)

3. **成本计算**:
   - 原料单价取最新采购价或移动平均价
   - 人工成本 = 标准工时 ÷ 60 × 人工小时单价
   - 制造费用按公司设定比例分摊
   - 实时计算,自动更新

4. **工序配置**:
   - 工序顺序支持拖拽排序
   - 工序时长之和应≤标准工时
   - 工作中心可关联设备资源

5. **状态控制**:
   - 新建时只能选择"草稿"或"启用"
   - 启用配方会自动停用同产品的其他启用版本
   - 编辑启用状态配方需先停用

2. **版本对比**:

3. **数据更新**:

##### 业务规则

1. **MRP运算逻辑**:
   ```
   毛需求 = Σ(生产计划产量 × 配方用量 × (1 + 损耗率))
   净需求 = 毛需求 - 当前库存 - 在途数量
   建议采购量 = MAX(净需求 + 安全库存, 0)
   ```

2. **到货日期计算**:
   - 建议到货日期 = 计划开始日期 - 采购提前期
   - 采购提前期从供应商档案获取

3. **数据来源**:
   - 生产计划: 主生产计划表
   - 配方用量: 配方管理
   - 当前库存: 库存管理实时查询
   - 在途数量: 采购管理未到货订单

4. **状态说明**:
   - **无需采购**: 净需求 ≤ 0
   - **需采购**: 净需求 > 0 且未生成采购申请
   - **已生成**: 已生成采购申请

##### 负荷率趋势图

- **X轴**: 日期
- **Y轴**: 负荷率(%)
- **基准线**: 100%产能线
- **预警线**: 80%预警线、120%超负荷线

##### 业务规则

1. **产能计算**:
   - 标准产能 = 工作中心人数 × 日工作时长 × 效率系数
   - 计划负荷 = Σ(生产工单标准工时)

   - **接近饱和**: 80% ≤ 负荷率 < 100%
   - **超负荷**: 负荷率 ≥ 100%

3. **预警机制**:

   - 负荷率 ≥ 100% 时红色预警
   - 超负荷时阻止新工单下达

## 数据流图

### 生产计划到工单执行

```
主生产计划
    │
    ├─> MRP运算 ──> 采购申请 (原料不足时)
    │
    └─> 下达工单
           │
           ├─> 生产领料 ──> 扣减原料库存
           │
           ├─> 生产报工 ──> 记录产量和工时
           │
           ├─> 质检记录 ──> 判定合格/不合格
           │
           └─> 成品入库 ──> 增加成品库存
```

### 委外加工流程

```
委外订单
    │
    ├─> 委外发料 ──> 扣减原料库存
    │       │
    │       └─> 在途物料
    │
    ├─> 供应商加工
    │
    ├─> 委外收货 ──> 质检
    │       │
    │       ├─> 合格 ──> 成品入库
    │       │
    │       └─> 不合格 ──> 退回或报废
    │
    └─> 委外结算 ──> 生成应付单
```

## 特别说明

1. **权限控制**: 所有操作按钮都有对应的权限码,自动化脚本需先检查用户权限
2. **数据校验**: 提交前必须通过前端校验,包括必填项、数据格式、业务规则
3. **弹窗处理**: 部分操作会触发确认弹窗,需等待弹窗出现后再点击确认
4. **级联选择**: 产品分类、工作中心等级联选择器需逐级展开
5. **动态加载**: 表格数据可能分页加载,需处理翻页逻辑
6. **实时计算**: 成本、用量等字段会实时计算,需等待计算完成
7. **批次管理**: 原料领料、成品入库都涉及批次号,需正确选择或生成批次号
8. **状态流转**: 工单、委外单等单据有严格的状态流转规则,不可跳过状态
