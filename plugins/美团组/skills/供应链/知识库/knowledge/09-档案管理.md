# 档案管理 - 详细文档

> **模块标识**: `#menucode_1842`
> **英文名称**: Archive Management
> **核心定位**: 美团供应链系统档案管理功能模块，实现供应链基础数据、业务档案、文档资料的统一管理和智能检索
> **版本信息**: v2.0 (Phase 2 详细版本)
> **完成度**: 75% (详细文档)

## 一、模块概述

### 1.1 功能定位

档案管理模块是美团供应链系统的数据中枢和知识库，负责管理供应链运营过程中产生的所有档案资料。主要负责:

- **基础档案管理**: 物品档案、供应商档案、客户档案、门店档案的建立和维护
- **业务档案管理**: 采购合同、销售合同、质检报告、认证文件的归档和管理
- **文档资料管理**: 操作手册、流程文档、培训资料、政策文件的分类存储
- **档案检索系统**: 全文检索、标签搜索、智能推荐、关联查询
- **权限控制**: 档案访问权限、编辑权限、下载权限、分享权限的精细化管理
- **版本管理**: 档案版本控制、变更记录、审批流程、历史追溯

### 1.2 核心价值

- ✅ **统一数据源**: 建立供应链唯一数据源，消除信息孤岛
- ✅ **智能检索**: 全文搜索、模糊匹配、智能推荐，快速定位所需档案
- ✅ **权限控制**: 多级权限体系，保障数据安全和合规性
- ✅ **版本追溯**: 完整的版本历史，支持任意时点数据查询
- ✅ **知识沉淀**: 业务知识系统化沉淀，降低培训成本
- ✅ **合规管理**: 符合食品安全、质量体系、财务审计等合规要求

### 1.3 与其他模块关联

**数据流入** (上游模块):
- **采购管理** → 供应商资质、采购合同 → 供应商档案库
- **销售管理** → 客户信息、销售合同 → 客户档案库
- **库存管理** → 物品信息、库位信息 → 物品档案库
- **质量管理** → 质检报告、认证文件 → 质量档案库
- **财务管理** → 财务凭证、审计报告 → 财务档案库

**数据流出** (下游模块):
- **所有业务模块** → 基础档案数据 → 业务单据填写
- **报表管理** → 档案统计数据 → 管理分析报表
- **预警管理** → 档案到期预警 → 合规风险提示
- **系统设置** → 档案分类规则 → 业务配置

**核心关联**:
- 与**所有模块**深度集成: 提供基础数据支撑
- 与**质量管理**紧密结合: 质量档案是质量追溯的基础
- 与**系统设置**协同: 档案分类、权限配置
- 与**预警管理**联动: 证照到期、合同到期预警

## 三、核心功能详解

### 3.1 基础档案管理

#### 3.1.1 物品档案 (#menucode_1842_01_01)

**功能说明**:
管理供应链所有物品(原料、半成品、成品)的完整档案信息，作为供应链运营的基础数据。

**核心字段**:

| 字段分类 | 字段名称 | 字段说明 | 数据类型 | 必填 |
|---------|---------|---------|---------|-----|
| **基本信息** | 物品编码 | 唯一标识码(支持自动生成/手动输入) | String(20) | ✅ |
| | 物品名称 | 物品中文名称 | String(100) | ✅ |
| | 物品英文名 | 物品英文名称(多语言支持) | String(100) | ❌ |
| | 物品简称 | 简写名称(用于打印小票) | String(50) | ❌ |
| | 条形码 | 标准条形码/二维码 | String(50) | ❌ |
| | 物品分类 | 多级分类(最多5级) | Tree | ✅ |
| | 物品规格 | 规格说明(如: 500g/袋) | String(100) | ✅ |
| | 计量单位 | 基本单位(如: kg, 个, 箱) | String(10) | ✅ |
| | 辅助单位 | 辅助计量单位及换算关系 | JSON | ❌ |
| **采购信息** | 采购单价 | 默认采购单价(含税/不含税) | Decimal(10,2) | ❌ |
| | 最低订货量 | MOQ (Minimum Order Quantity) | Decimal(10,2) | ❌ |
| | 采购提前期 | 订货到货周期(天) | Integer | ❌ |
| | 默认供应商 | 主力供应商ID | Reference | ❌ |
| | 备用供应商 | 备选供应商列表 | Array | ❌ |
| **库存信息** | 安全库存 | 最低库存预警线 | Decimal(10,2) | ❌ |
| | 最高库存 | 最高库存预警线 | Decimal(10,2) | ❌ |
| | 库存计价方式 | FIFO(先进先出)/加权平均/移动平均 | Enum | ✅ |
| | 保质期 | 保质期天数 | Integer | ❌ |
| | 存储条件 | 常温/冷藏/冷冻/特殊条件 | Enum | ❌ |
| **质量信息** | 质量标准 | 国标/企标/行业标准编号 | String(100) | ❌ |
| | 质检要求 | 入库质检/抽检/免检 | Enum | ❌ |
| | 产地信息 | 原产地/生产基地 | String(200) | ❌ |
| | 品牌信息 | 品牌名称 | String(100) | ❌ |
| **财务信息** | 成本价格 | 标准成本/最新成本 | Decimal(10,2) | ❌ |
| | 销售价格 | 默认销售单价 | Decimal(10,2) | ❌ |
| | 税率 | 增值税率(%) | Decimal(5,2) | ❌ |
| | 利润率 | 目标利润率(%) | Decimal(5,2) | ❌ |
| **附件信息** | 产品图片 | 主图+多图(最多9张) | Image[] | ❌ |
| | 产品说明书 | PDF/Word文档 | File | ❌ |
| | 质检报告 | 第三方检测报告 | File | ❌ |
| | 认证证书 | 有机认证/绿色食品等 | File | ❌ |

**业务流程**:

```
1. 新增物品档案
   → 填写基本信息(编码、名称、分类、规格、单位)
   → 设置采购信息(供应商、采购价、订货量)
   → 配置库存信息(安全库存、计价方式、保质期)
   → 上传附件(图片、说明书、质检报告)
   → 提交审核(需要时)
   → 生效启用

2. 修改物品档案
   → 搜索定位目标物品
   → 编辑字段信息
   → 记录变更原因
   → 提交审核(价格变动需审批)
   → 更新生效

3. 物品档案停用
   → 检查库存余额(需清零)
   → 检查在途订单(需完成)
   → 设置停用状态
   → 归档保存

4. 物品档案导入
   → 下载标准模板
   → 填写物品信息
   → 导入Excel文件
   → 系统校验(编码重复、必填项检查)
   → 导入成功/失败报告
```

**权限控制**:
- **查看权限**: 所有供应链人员
- **新增权限**: 采购专员、仓库主管
- **修改权限**: 采购主管、供应链经理
- **删除权限**: 系统管理员(仅限未使用档案)
- **审批权限**: 供应链总监(价格变动>10%)

| | 综合评分 | 系统自动计算综合得分 | Decimal(5,2) | Auto |

**业务流程**:

```
1. 新增供应商档案
   → 填写基本信息(编码、名称、类型、等级)
   → 录入注册信息(营业执照信息)
   → 添加联系信息(联系人、电话、地址)
   → 配置财务信息(银行账号、付款方式)
   → 上传资质证照(营业执照、许可证、认证)
   → 设置供货信息(品类、范围、配送)
   → 提交审核
   → 审核通过后生效

2. 供应商资质更新
   → 系统自动预警证照到期(提前30天)
   → 联系供应商获取新证照
   → 上传新证照文件
   → 更新有效期
   → 归档旧证照

3. 供应商绩效评估
   → 系统每月自动统计:
     - 采购订单数量/金额
     - 准时交货次数/延迟次数
     - 质检合格数/不合格数
     - 退货次数/退货金额
   → 自动计算绩效指标
   → 生成供应商绩效报告
   → 根据评分调整供应商等级

4. 供应商黑名单管理
   → 严重质量问题/违约行为
   → 加入黑名单
   → 系统自动拦截采购单
   → 通知相关部门
```

**权限控制**:
- **查看权限**: 所有采购人员
- **新增权限**: 采购专员
- **修改权限**: 采购主管
- **资质更新**: 采购专员、质量专员
- **等级调整**: 采购经理
- **黑名单管理**: 供应链总监

    ↓
[定期维护]
    ↓

    ↓
[异常处理]
    ↓

```

    ↓
检查所有资质证照有效期
    ↓
计算距离到期天数
    ↓
[90天内到期] → 绿色提示 → 系统消息通知
    ↓
[60天内到期] → 黄色预警 → 系统消息 + 邮件通知
    ↓
[30天内到期] → 红色预警 → 系统消息 + 邮件 + 短信
    ↓

    ↓

    ↓

```

## 七、最佳实践建议

### 7.1 档案建立最佳实践

**物品档案建立**:
1. ✅ 统一编码规则: 采用分类码+流水号(如: `SC-001-0001`)
2. ✅ 完整填写必填项: 编码、名称、分类、规格、单位、计价方式
3. ✅ 上传高清图片: 主图分辨率≥800x800px
4. ✅ 关联供应商: 设置默认供应商和备用供应商
5. ✅ 设置安全库存: 根据历史销量合理设置库存预警线

**供应商档案建立**:
1. ✅ 收集完整资质: 营业执照、许可证、认证证书一个不能少
2. ✅ 核实信息真实性: 通过企查查/天眼查等工具验证
3. ✅ 设置合理账期: 根据供应商规模和合作历史设置
4. ✅ 建立评估机制: 定期评估质量、交期、价格、服务
5. ✅ 备份联系方式: 至少2个联系人,防止单点失联

### 7.2 档案维护最佳实践

**定期审核**:
- 每季度审核一次基础档案(物品/供应商/客户)
- 每月审核一次资质证照有效期
- 每周审核一次合同执行进度

**变更管理**:
- 重要字段变更(价格/账期)必须审批
- 记录变更原因和变更人
- 保留变更历史,支持回溯

**数据清理**:
- 定期清理僵尸档案(1年以上无交易)
- 合并重复档案
- 归档停用档案(不删除,只标记停用)

### 7.3 权限管理最佳实践

**最小权限原则**:
- 仅授予完成工作所需的最小权限
- 定期审查权限,回收不必要的权限
- 敏感档案(合同/财务)严格控制访问

**审计追踪**:
- 记录所有档案访问日志
- 记录所有档案修改历史
- 异常访问行为预警

**数据安全**:
- 重要档案加密存储
- 定期备份档案数据
- 分享档案添加水印

## 八、常见问题FAQ

**Q1: 如何快速找到某个供应商的所有资质证照?**
A: 进入"供应商档案" → 点击目标供应商 → 切换到"资质证照"Tab → 查看该供应商所有证照及有效期

**Q2: 合同即将到期,如何处理?**
A: 系统会提前30天预警 → 联系供应商洽谈续约 → 签订新合同 → 上传合同扫描件 → 提交审批 → 生效

**Q3: 如何批量导入物品档案?**
A: 下载标准模板(Excel) → 填写物品信息 → 检查必填项和格式 → 导入系统 → 查看导入报告 → 处理错误数据

**Q4: 供应商资质过期了,系统会自动拦截采购吗?**
A: 是的。食品经营许可证过期后,系统自动拦截该供应商的所有采购订单,直到资质更新。

**Q5: 如何给外部合作方临时分享档案?**
A: 点击档案详情 → "分享"按钮 → 设置访问密码和有效期 → 生成分享链接 → 发送给对方

**Q6: 档案被误删除了,能恢复吗?**
A: 档案删除需要特殊权限,且有审批流程。已删除档案可在"回收站"恢复(保留30天)。

**Q7: 如何查看档案的变更历史?**
A: 打开档案详情 → 点击"变更历史"Tab → 查看所有字段变更记录(时间/变更人/变更前后值)

**Q8: 如何设置档案自动预警?**
A: 进入"档案配置" → "预警规则" → 设置预警条件(到期天数/金额阈值) → 设置通知方式和接收人
