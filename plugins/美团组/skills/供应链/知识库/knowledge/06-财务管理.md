# 财务管理 - 详细文档

> **模块标识**: `#menucode_2015`
> **英文名称**: Financial Management
> **核心定位**: 美团供应链系统财务管理功能模块，实现供应链财务核算、成本管理、资金管理和财务分析的一体化管理
> **版本信息**: v2.0 (Phase 2 详细版本)
> **完成度**: 75% (详细文档)

## 一、模块概述

### 1.1 功能定位

财务管理模块是美团供应链系统的财务核心，基于供应链业务数据自动生成财务凭证，实现业财一体化。主要负责：

- **成本核算**: 采购成本、生产成本、销售成本的全流程核算
- **资金管理**: 应收应付账款、付款计划、资金流监控
- **财务报表**: 损益表、资产负债表、现金流量表等标准报表
- **预算管理**: 预算编制、预算执行、预算差异分析
- **结账管理**: 期末结账、成本结转、账套管理
- **财务分析**: 经营分析、成本分析、利润分析

### 1.2 核心价值

- ✅ **业财一体化**: 供应链业务自动生成财务凭证，减少人工录入
- ✅ **实时成本核算**: 实时计算采购成本、生产成本、销售成本
- ✅ **多维度分析**: 按门店、商品、供应商、时间等多维度分析财务数据
- ✅ **资金风险预警**: 应收账款账龄分析、资金缺口预警
- ✅ **决策支持**: 财务报表和经营分析为管理决策提供数据支持

### 1.3 与其他模块关联

**数据流入** (上游模块):
- **采购管理** → 采购订单、采购入库单 → 应付账款、采购成本
- **销售管理** → 销售订单、销售出库单 → 应收账款、销售收入
- **生产管理** → 生产工单、领料单 → 生产成本
- **库存管理** → 盘点单、调拨单 → 库存成本变动
- **配送管理** → 配送单、物流费用 → 运输成本

**数据流出** (下游模块):
- **报表管理** → 财务报表数据 → 经营分析报表
- **预警管理** → 资金预警、成本异常 → 风险提示
- **系统设置** → 会计科目、核算规则 → 财务配置

**核心关联**:
- 与**采购管理**深度集成: 采购价格、付款条款影响成本和资金流
- 与**销售管理**紧密结合: 销售价格、回款周期影响收入和资金流
- 与**生产管理**协同: 生产成本实时核算，工单成本分析
- 与**库存管理**联动: 库存成本计价方法(FIFO/加权平均)影响成本核算

## 3.1 成本管理

### 3.1.1 成本核算

**页面路径**: 财务管理 → 成本管理 → 成本核算
**Hash路由**: `#/financial/cost-accounting`
**CSS选择器**: `#menucode_2015_01_01`

**功能描述**:
实时核算采购成本、生产成本、销售成本，支持按商品、门店、时间段查询成本明细。

#### 查询表单字段

| 字段名 | 类型 | 必填 | 说明 | CSS选择器 |
|--------|------|------|------|-----------|
| 成本类型 | 下拉单选 | 否 | 采购成本/生产成本/销售成本 | `select[name="costType"]` |
| 商品名称 | 搜索下拉 | 否 | 支持模糊搜索 | `input[name="productName"]` |
| 所属门店 | 下拉单选 | 否 | 仅门店角色显示本店 | `select[name="storeId"]` |
| 成本期间 | 日期范围 | 是 | 默认当月 | `input[name="costPeriodStart"]`, `input[name="costPeriodEnd"]` |
| 供应商 | 搜索下拉 | 否 | 采购成本时可选 | `input[name="supplierId"]` |

#### 数据表格

| 列名 | 数据类型 | 排序 | 筛选 | 说明 |
|------|----------|------|------|------|
| 商品编码 | 字符串 | ✓ | ✓ | 点击查看成本明细 |
| 商品名称 | 字符串 | ✓ | ✓ | - |
| 规格型号 | 字符串 | ✗ | ✗ | - |
| 单位 | 字符串 | ✗ | ✗ | kg/个/件/箱 |
| 期初库存 | 数值 | ✗ | ✗ | 期初数量 |
| 期初成本 | 金额 | ✗ | ✗ | 期初总成本 |
| 本期入库数量 | 数值 | ✓ | ✗ | 采购入库+生产入库 |
| 本期入库成本 | 金额 | ✓ | ✗ | 入库总成本 |
| 本期出库数量 | 数值 | ✓ | ✗ | 销售出库+生产领料 |
| 本期出库成本 | 金额 | ✓ | ✗ | 出库总成本 |
| 期末库存 | 数值 | ✓ | ✗ | 期末数量 |
| 期末成本 | 金额 | ✓ | ✗ | 期末总成本 |
| 单位成本 | 金额 | ✓ | ✗ | 期末成本/期末库存 |
| 计价方法 | 枚举 | ✗ | ✓ | FIFO/移动加权/月末加权 |

#### 操作按钮

| 按钮 | 功能 | CSS选择器 | 备注 |
|------|------|-----------|------|
| 查询 | 执行查询 | `.btn-query` | 主要按钮 |
| 重置 | 清空查询条件 | `.btn-reset` | 次要按钮 |
| 导出 | 导出Excel | `.btn-export` | 需权限 |
| 成本明细 | 查看成本构成 | `.btn-cost-detail` | 表格行操作 |
| 成本追溯 | 追溯成本来源 | `.btn-cost-trace` | 表格行操作 |

#### 业务规则

1. **成本计算公式**:
   ```
   期末成本 = 期初成本 + 本期入库成本 - 本期出库成本
   单位成本 = 期末成本 ÷ 期末库存数量
   ```

2. **计价方法**:
   - **FIFO (先进先出)**: 先入库的商品先出库，适合生鲜等保质期短的商品
   - **移动加权平均**: 每次入库后重新计算平均成本，实时更新
   - **月末加权平均**: 月末统一计算平均成本，适合标准化商品

3. **成本结转时机**:
   - 采购成本: 采购入库单审核通过时结转
   - 生产成本: 生产入库单审核通过时结转
   - 销售成本: 销售出库单审核通过时结转

4. **成本调整**:
   - 支持盘盈盘亏成本调整
   - 支持历史成本回溯调整
   - 调整需审批流程

### 3.1.2 成本分析

**页面路径**: 财务管理 → 成本管理 → 成本分析
**Hash路由**: `#/financial/cost-analysis`
**CSS选择器**: `#menucode_2015_01_02`

**功能描述**:
多维度分析成本构成、成本趋势、成本差异，支持按商品类别、供应商、门店等维度分析。

#### 分析维度配置

| 维度类型 | 说明 | 示例 |
|---------|------|------|

| 供应商维度 | 按供应商分析采购成本 | 供应商A、供应商B |
| 门店维度 | 按门店分析成本差异 | 门店1、门店2、门店3 |
| 时间维度 | 按日/周/月分析成本趋势 | 2025-11月、2025-Q4 |
| 成本结构 | 按成本构成分析占比 | 原材料成本、人工成本、制造费用 |

#### 查询表单字段

| 字段名 | 类型 | 必填 | 说明 | CSS选择器 |
|--------|------|------|------|-----------|
| 分析维度 | 下拉单选 | 是 | 商品/供应商/门店/时间 | `select[name="analysisDimension"]` |
| 时间范围 | 日期范围 | 是 | 默认最近3个月 | `input[name="dateRange"]` |
| 对比期间 | 日期范围 | 否 | 用于同比环比 | `input[name="compareDateRange"]` |
| 门店 | 多选下拉 | 否 | 可选多个门店对比 | `select[name="storeIds"]` |
| 商品类别 | 多选下拉 | 否 | 一级/二级类别 | `select[name="categoryIds"]` |

#### 图表展示

1. **成本构成饼图**:
   - 显示原材料成本、人工成本、制造费用占比
   - 支持钻取查看明细

2. **成本趋势折线图**:
   - X轴: 时间(日/周/月)
   - Y轴: 成本金额
   - 支持多商品/多门店对比

3. **成本对比柱状图**:
   - 同比环比成本对比
   - 预算成本vs实际成本对比

#### 业务规则

1. **成本差异分析**:
   ```
   成本差异 = 实际成本 - 预算成本
   成本差异率 = (实际成本 - 预算成本) / 预算成本 × 100%
   ```

2. **成本趋势判断**:
   - **成本上升**: 连续3个月成本增长
   - **成本异常**: 单月成本波动超过20%
   - **成本优化**: 连续3个月成本下降

3. **预警规则**:
   - 成本差异率 > 10%: 黄色预警
   - 成本差异率 > 20%: 红色预警
   - 自动推送预警通知

### 3.1.3 成本监控

**页面路径**: 财务管理 → 成本管理 → 成本监控
**Hash路由**: `#/financial/cost-monitoring`
**CSS选择器**: `#menucode_2015_01_03`

**功能描述**:
实时监控成本异常、成本预警、成本KPI，支持设置成本阈值自动预警。

#### 监控指标

| 指标名称 | 计算公式 | 阈值设置 | 预警级别 |
|---------|---------|---------|---------|
| 食材成本率 | 食材成本/销售收入 | > 35% | 黄色预警 |
| 人工成本率 | 人工成本/销售收入 | > 20% | 黄色预警 |
| 综合成本率 | 总成本/销售收入 | > 65% | 红色预警 |
| 单位成本涨幅 | (本月单价-上月单价)/上月单价 | > 10% | 黄色预警 |
| 库存周转天数 | 平均库存/日均销售成本 | > 15天 | 黄色预警 |

#### 预警规则配置

| 字段名 | 类型 | 必填 | 说明 | CSS选择器 |
|--------|------|------|------|-----------|
| 指标名称 | 下拉单选 | 是 | 选择监控指标 | `select[name="metricName"]` |
| 预警阈值 | 数值输入 | 是 | 触发预警的阈值 | `input[name="threshold"]` |
| 预警级别 | 下拉单选 | 是 | 黄色/红色 | `select[name="alertLevel"]` |
| 通知方式 | 多选框 | 是 | 系统通知/邮件/短信 | `input[name="notifyMethod"]` |
| 接收人 | 多选下拉 | 是 | 选择预警接收人 | `select[name="recipients"]` |

#### 业务规则

1. **实时监控频率**:
   - 关键指标: 每小时更新
   - 一般指标: 每日更新
   - 历史数据: 每月归档

2. **预警触发条件**:
   - 单次超阈值: 立即预警
   - 连续3次超阈值: 升级预警
   - 恢复正常: 自动解除预警

3. **预警处理流程**:
   - 系统自动预警 → 通知相关人员 → 人工分析原因 → 制定改进措施 → 跟踪执行效果

#### 业务规则

1. **账龄计算**:
   ```
   账龄天数 = 当前日期 - 应收账款业务日期
   逾期天数 = 账龄天数 - 客户信用期
   ```

2. **账龄区间**:
   - 0-30天: 正常账龄
   - 31-60天: 关注账龄
   - 61-90天: 风险账龄
   - >90天: 高风险账龄

3. **信用额度控制**:
   ```
   可用额度 = 客户信用额度 - 未收金额合计
   ```
   - 可用额度 < 0: 禁止新增销售订单
   - 可用额度 < 信用额度10%: 黄色预警

4. **坏账准备计提**:
   - 0-30天: 不计提
   - 31-60天: 计提5%
   - 61-90天: 计提10%
   - >90天: 计提30%

   ```javascript
   let remainAmount = receiptAmount; // 剩余待核销金额
   const receivables = getReceivablesByCustomer(customerId).sort((a, b) =>
     new Date(a.businessDate) - new Date(b.businessDate)
   ); // 按业务日期升序

   for (const receivable of receivables) {
     if (remainAmount <= 0) break;

     const unpaidAmount = receivable.unpaidAmount;
     if (remainAmount >= unpaidAmount) {
       // 全额核销
       receivable.paidAmount += unpaidAmount;
       receivable.settlementStatus = '已结清';
       remainAmount -= unpaidAmount;
     } else {
       // 部分核销
       receivable.paidAmount += remainAmount;
       receivable.settlementStatus = '部分结清';
       remainAmount = 0;
     }
   }

   if (remainAmount > 0) {
     // 记为预收款
     createAdvanceReceipt(customerId, remainAmount);
   }
   ```

   ```
   本期预算 = 从零开始重新核算
   ```
   适用于业务变化大的企业

3. **弹性预算法**:
   ```
   固定成本预算 = 固定值
   变动成本预算 = 单位变动成本 × 预计业务量
   ```
   适用于成本费用项目

#### 业务规则

1. **预算审批流程**:
   - 部门编制 → 财务审核 → 总经理审批 → 下达执行

2. **预算调整规则**:
   - 预算执行中可申请调整
   - 调整幅度<10%: 财务总监审批
   - 调整幅度≥10%: 总经理审批

## 五、业务规则总结

### 5.1 成本核算规则

1. **计价方法**:
   - FIFO: 先进先出,适合生鲜
   - 移动加权平均: 实时更新,适合标准品
   - 月末加权平均: 月末计算,适合大宗商品

2. **成本结转时机**:
   - 采购成本: 入库审核时
   - 生产成本: 完工入库时
   - 销售成本: 出库审核时

3. **成本差异分析**:
   - 差异 = 实际成本 - 预算成本
   - 差异率 = 差异 / 预算成本 × 100%

### 5.2 资金管理规则

1. **应收账款管理**:
   - 账龄计算: 当前日期 - 业务日期
   - 信用额度控制: 可用额度 = 信用额度 - 未收金额
   - 坏账准备计提: 按账龄比例计提

2. **应付账款管理**:
   - 到期日计算: 业务日期 + 付款期限
   - 付款优先级: 逾期 > 即将到期 > 正常
   - 对账规则: 按月对账,差异>1%需重新对账

3. **付款审批额度**:
   - <1万: 财务经理
   - 1-5万: 财务总监
   - >5万: 总经理

### 5.3 财务报表规则

1. **损益表关键公式**:
   ```
   毛利润 = 营业收入 - 营业成本
   毛利率 = 毛利润 / 营业收入 × 100%
   营业利润 = 毛利润 - 期间费用
   净利润 = 利润总额 - 所得税
   ```

2. **资产负债表平衡**:
   ```
   资产 = 负债 + 所有者权益
   ```

3. **现金流量表分类**:
   - 经营活动: 日常经营收支
   - 投资活动: 固定资产投资
   - 筹资活动: 融资和还款

### 5.4 预算管理规则

1. **预算编制方法**:
   - 增量预算: 基于上期实际
   - 零基预算: 从零开始核算
   - 弹性预算: 区分固定和变动成本

2. **预算差异预警**:
   - 差异率 > 10%: 黄色预警
   - 差异率 > 20%: 红色预警

3. **预算调整规则**:
   - <10%调整: 财务总监审批
   - ≥10%调整: 总经理审批

### 5.5 结账管理规则

1. **结账时间**:
   - 每月5日前完成上月结账
   - 必须按月份顺序结账

2. **结账前检查**:
   - 所有单据已审核
   - 库存盘点已完成
   - 成本核算已完成
   - 往来对账已完成

3. **反结账规则**:
   - 只能反结账最近一期
   - 需财务总监审批
