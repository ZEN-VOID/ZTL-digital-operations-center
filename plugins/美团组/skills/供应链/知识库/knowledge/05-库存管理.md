# 05-库存管理 (Inventory Management)

## 模块概述

### 模块定位
库存管理模块是美团供应链管理系统的核心模块之一,负责总部、配送中心、门店三级库存体系的全生命周期管理。该模块涵盖实时库存查询、库存出入库、盘点管理、库存调拨、保质期预警等核心功能,与采购管理、配送管理、生产管理、财务管理深度集成,确保库存数据的准确性和实时性。

### 核心功能
- 实时库存查询与监控
- 出入库单据管理(采购入库、销售出库、生产入库、生产领料、其他出入库)
- 库存盘点管理(盘点计划、盘点执行、盘点差异处理)
- 机构间调拨管理(总部→配送中心→门店)
- 库存批次管理(批次号、生产日期、保质期追溯)
- 保质期预警与效期管理
- 库存呆滞品分析与处理
- 库存周转率统计
- 库存上下限预警

### 与其他模块的关联
```
库存管理
├── ← 采购管理: 采购收货触发入库,增加库存
├── ← 配送管理: 配送发货触发出库,减少库存
├── ← 生产管理: 生产领料出库,生产完工入库
├── ← 销售管理: 销售订单触发库存锁定和出库
├── → 财务管理: 库存金额计算,库存盘点差异影响成本
├── → 报表管理: 提供库存数据源,生成分析报表
├── ← 档案管理: 调用物品档案、仓库档案、单位换算
├── → 预警管理: 触发库存上下限预警、保质期预警、呆滞品预警
└── ← 系统设置: 成本计价方式(先进先出/移动加权平均/月末一次性加权)
```

##### 业务规则
1. **库存计算公式**:
   - 当前库存 = 期初库存 + 所有入库 - 所有出库
   - 可用库存 = 当前库存 - 锁定库存
   - 锁定库存 = 销售订单锁定 + 生产计划锁定 + 配送单锁定
   - 在途库存 = 采购订单在途 + 调拨单在途 + 生产工单在途

2. **库存预警逻辑**:
   - 高于上限预警: 当前库存 > 库存上限 × 1.2
   - 低于下限预警: 当前库存 < 库存下限
   - 零库存预警: 当前库存 = 0 且库存下限 > 0

3. **成本计价方式**:
   - 先进先出(FIFO): 先入库的先出库,库存成本按最早批次计算
   - 移动加权平均: 库存成本 = (期初库存金额 + 本期入库金额) / (期初库存数量 + 本期入库数量)
   - 月末一次性加权平均: 月末统一计算加权平均成本

4. **权限控制**:
   - 总部用户: 可查询所有机构的库存
   - 配送中心用户: 可查询本配送中心及所属门店的库存
   - 门店用户: 只能查询本门店的库存
   - 仓库管理员: 可进行库存调整操作

##### 业务规则
1. **保质期判定**:
   - 正常: 剩余保质期 > 保质期×30%
   - 临期: 保质期×10% < 剩余保质期 ≤ 保质期×30%
   - 过期: 剩余保质期 ≤ 0

2. **批次出库顺序(先进先出)**:
   - 优先出库生产日期最早的批次
   - 同一天生产的,优先出库批次号小的
   - 临期批次优先于正常批次出库

3. **批次冻结规则**:
   - 冻结后不可出库,但可以继续入库
   - 冻结原因:质量问题、供应商问题、客诉追溯
   - 解冻需要质量主管或以上权限

##### 业务规则

   - 支持分批入库,多次入库累计不能超过订单数量
   - 超量入库需要特殊审批

   - 如物品档案设置"启用批次管理",则必须填写批次号、生产日期
   - 同一物品的不同批次可以在同一入库单中
   - 批次号+物品编码必须唯一

5. **审核与冲销**:
   - 审核后库存立即增加
   - 冲销后库存立即减少,需要足够的可用库存才能冲销
   - 冲销原因:退货、质量问题、数据录入错误

##### 业务规则
1. **调拨权限**:
   - 调入方:可创建调拨申请单
   - 调出方:可审批、拒绝、发货
   - 总部:可查看和审批所有调拨单

2. **库存控制**:
   - 创建调拨单后,调出方库存锁定(不可用于其他业务)
   - 审批通过后,锁定继续保留
   - 发货后,调出方库存减少,锁定解除
   - 收货后,调入方库存增加

3. **差异处理**:
   - 实际发货数量 < 申请数量:部分发货,可补发或取消余量
   - 实际收货数量 < 发货数量:差异原因(破损、丢失),调出方补发或调入方承担损失
   - 实际收货数量 > 发货数量:不允许,必须与发货数量一致

4. **成本核算**:
   - 调拨价格 = 调出方库存成本
   - 调入方以调出方成本价入库
   - 运费单独核算,不计入库存成本

##### 周转率计算公式
```
库存周转率 = 本期销售成本 / 平均库存成本
库存周转天数 = 统计周期天数 / 库存周转率
平均库存成本 = (期初库存成本 + 期末库存成本) / 2
```

##### 周转率分级
| 周转率级别 | 周转天数 | 评价 | 建议 |
|-----------|----------|------|------|
| A级(快速周转) | <15天 | 优秀 | 保持现状 |
| B级(正常周转) | 15-30天 | 良好 | 保持现状 |
| C级(缓慢周转) | 31-60天 | 一般 | 控制进货,促销 |
| D级(呆滞) | 61-90天 | 较差 | 清理库存 |

## 自动化场景

### 场景1:采购收货自动入库
**触发条件**: 采购订单完成验收
**自动化流程**:
1. 从采购订单提取收货数据(物品、数量、单价、供应商、批次)
2. 自动创建采购入库单,填充表单字段
3. 如物品启用批次管理,自动生成批次号(格式:YYYYMMDD-SUP-XXXX)
4. 自动填写生产日期(从验收记录带入)
5. 自动计算到期日期(生产日期+保质期)
6. 质检合格后,自动提交审核
7. 审核通过后,库存实时增加
8. 触发库存预警检查,如超过上限则发送通知

**CSS选择器路径**:
```
采购订单详情页 → `.btn-create-inbound` → 入库单表单 → 自动填充
入库单表单 → `.btn-auto-generate-batch` → 批次号生成
入库单表单 → `.btn-submit-approve` → 提交审核
```

### 场景2:销售订单自动出库
**触发条件**: 销售订单审批通过
**自动化流程**:
1. 锁定库存:根据销售订单明细,锁定对应物品的可用库存
2. 检查库存充足性:如库存不足,触发缺货预警,通知采购部门
3. 自动创建销售出库单,关联销售订单
4. 批次分配:按先进先出原则,自动分配批次(优先临期批次)
5. 生成配送任务:创建配送单,分配配送路线
6. 出库审核:仓库主管审核后,库存实时减少,锁定解除
7. 更新销售订单状态:订单状态变为"已出库"
8. 触发库存预警检查:如低于下限则发送补货通知

**CSS选择器路径**:
```
销售订单详情页 → `.btn-create-outbound` → 出库单表单 → 自动填充
出库单表单 → `.btn-auto-allocate-batch` → 批次自动分配(FIFO)
出库单表单 → `.btn-submit-approve` → 提交审核
```

### 场景3:库存盘点自动化
**触发条件**: 每月月末23:00自动触发
**自动化流程**:
1. 自动创建盘点计划:盘点类型=全盘,盘点所有仓库
2. 生成盘点快照:记录当前时刻的账面库存数量
3. 冻结库存:盘点期间禁止出入库操作(可选)
4. 发送盘点通知:通知所有仓库管理员开始盘点
5. 导出盘点清单:Excel格式,包含物品编码、名称、账面数量
6. 移动端盘点:仓库人员使用手机扫码录入实际数量
7. 差异计算:实际数量-账面数量,标记盘盈/盘亏
8. 自动审批(差异金额<1000元):差异小的自动审批通过
9. 人工审批(差异金额≥1000元):差异大的提交财务主管审批
10. 账面调整:审批通过后,账面库存调整为实际数量
11. 生成盘点报告:盘点盈亏表、盘点汇总报表
12. 发送盘点结果:邮件通知财务部门、采购部门、仓库管理员

**触发时机**: 定时任务(Cron表达式:0 0 23 L * ?),每月最后一天23:00执行

### 场景4:临期物品自动预警
**触发条件**: 每日早上6:00自动检查
**自动化流程**:
1. 扫描所有启用批次管理的物品库存
2. 计算剩余保质期:到期日期-当前日期
3. 判定预警级别:
   - 剩余≤10%保质期 → 红色预警
   - 10%<剩余≤30%保质期 → 橙色预警
   - 30%<剩余≤50%保质期 → 黄色预警
4. 生成预警清单:包含物品、批次、库存、金额、剩余天数
5. 自动生成处理建议:
   - 红色预警 → 建议报废或促销
   - 橙色预警 → 建议优先发货或调拨
   - 黄色预警 → 建议关注库存,控制进货
6. 发送预警通知:
   - 红色预警 → 短信+站内消息,通知仓库主管、采购经理
   - 橙色预警 → 站内消息,通知仓库管理员
   - 黄色预警 → 站内消息,记录预警日志
7. 自动创建促销方案(红色预警 且 库存金额>5000元):
   - 促销价格 = 成本价×1.1(保本促销)
   - 促销时间 = 7天
   - 促销门店 = 该批次所在门店
8. 自动创建调拨方案(红色预警 且 其他门店有需求):
   - 查询其他门店该物品的库存和需求
   - 生成调拨建议:调出方=当前机构,调入方=需求机构,调拨数量=需求数量
9. 自动报废(已过期 且 审批通过):
   - 过期物品自动生成报废单
   - 报废金额<500元:自动审批
   - 报废金额≥500元:提交仓库主管审批

**触发时机**: 定时任务(Cron表达式:0 0 6 * * ?),每日早上6:00执行

### 场景5:库存上下限自动补货
**触发条件**: 每日早上7:00自动检查
**自动化流程**:
1. 查询所有物品的当前库存、库存下限、库存上限
2. 筛选低库存物品:当前库存 < 库存下限
3. 计算补货数量:补货数量 = 库存上限 - 当前库存
4. 考虑在途库存:补货数量 = 库存上限 - 当前库存 - 在途库存
5. 考虑最小起订量:如补货数量 < 最小起订量,则调整为最小起订量
6. 自动创建采购申请单:
   - 物品:低库存物品
   - 数量:补货数量
   - 供应商:主供应商(从物品档案获取)
   - 要求交货日期:当前日期+供应商交货周期
7. 发送补货通知:站内消息通知采购员
8. 采购员确认后,自动创建采购订单
9. 供应商确认后,更新在途库存

**触发时机**: 定时任务(Cron表达式:0 0 7 * * ?),每日早上7:00执行

**CSS选择器路径**:
```
库存查询表 → `.btn-auto-replenish` → 自动补货
补货建议表 → `.btn-create-purchase` → 创建采购申请单
```

### 附录B:成本计价方式对比
| 计价方式 | 说明 | 优点 | 缺点 | 适用场景 |
|---------|------|------|------|---------|
| 先进先出(FIFO) | 先入库先出库,成本按入库顺序计算 | 符合实物流转,成本准确 | 计算复杂,系统要求高 | 有保质期的物品 |
| 移动加权平均 | 入库后立即重算平均成本 | 成本平滑,计算实时 | 频繁入库时计算量大 | 价格波动大的物品 |
| 月末一次性加权平均 | 月末统一计算平均成本 | 计算简单,月内成本稳定 | 月内成本不准确 | 价格稳定的物品 |
