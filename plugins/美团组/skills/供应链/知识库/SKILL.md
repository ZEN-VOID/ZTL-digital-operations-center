## 🎯 核心模块速查

### 模块1: 配送管理 (menucode_1887)

**核心功能**:
- 门店订货单: 门店发起订货
- 配送单: 配送中心处理配送
- 配送规则: 方式、价格、范围设置
- 配送差异: 差异处理
- 配送返货: 退货管理

**关键字段**: 订货单号、物品、数量、配送日期、配送中心、门店

**业务流程**: 门店订货 → 配送中心审核 → 拣货打包 → 配送发货 → 门店收货

### 模块2: 采购管理 (menucode_1866)

**核心功能**:
- 采购订单: 创建采购订单
- 采购收货: 收货验收
- 供应商管理: 供应商档案
- 采购模板: 快速采购
- 采购定价: 价格协议

**关键字段**: 采购单号、供应商、物品、数量、单价、交货日期

**业务流程**: 创建采购订单 → 供应商确认 → 供应商发货 → 配送中心收货 → 质检入库

### 模块3: 库存管理 (menucode_1907)

**核心功能**:
- 实时库存查询: 当前库存状态
- 库存盘点: 盘点流程管理
- 库存调拨: 配送中心间调拨
- 库存报损: 损耗处理
- 库存预警: 上下限预警

**关键字段**: 物品、仓库、当前库存、可用库存、冻结库存、库存成本

**业务流程**: 盘点计划 → 盘点执行 → 差异分析 → 盘点审核 → 库存调整

### 模块4: 财务管理 (menucode_2015)

**核心功能**:
- 应收对账: 门店应收管理
- 应付对账: 供应商应付管理
- 成本核算: 物品成本计算
- 财务报表: 经营分析报表

**关键字段**: 单据号、对账金额、已付金额、未付金额、对账状态
