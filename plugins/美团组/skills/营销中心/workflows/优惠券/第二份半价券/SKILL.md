# 第二份半价券创建技能包 (Second Half Price Coupon Creator)

## 概述

这是一个**标准操作流程(SOP)型技能包**,用于在美团管家后台快速创建"第二份半价券"营销活动。遵循**三层架构模式**,支持单个和批量创建,能够智能解析自然语言描述或结构化数据,自动生成符合美团平台规范的优惠券配置方案。

**业务目标**:
- 🎯 提升客单价: 通过"第N份折扣"激励顾客增加购买数量
- 🚀 快速上线: 标准化配置流程,5分钟内完成活动创建
- 📊 精准营销: 支持商品范围、用户群体、时间段的精细化配置
- 🔄 批量管理: 支持多SKU、多门店的批量优惠券创建

**适用场景**:
- ✅ 堂食场景: 鼓励顾客多点菜品,提升桌均消费
- ✅ 外卖场景: 刺激用户凑单,提高订单金额
- ✅ 新品推广: 第二份半价吸引试吃,加速新品渗透
- ✅ 节假日促销: 节日营销活动的常用优惠形式

## 核心能力

### 1. 多源信息解析

**支持输入格式**:
- ✅ 自然语言描述 (中文/英文)
- ✅ 结构化数据 (JSON/YAML)
- ✅ 美团后台配置表单 (键值对)
- ✅ 批量配置文件 (Excel/CSV)

**智能提取能力**:
- 活动基本信息 (活动名称、时间范围、预算)
- 折扣规则 (第几份、折扣比例)
- 适用范围 (商品、门店、渠道)
- 使用限制 (用户限领、每单限用、最低消费)
- 展示配置 (活动标签、推广文案)

### 2. 优惠券核心配置

#### 活动基本信息

**必填字段**:
- **活动名称**: 50字符以内,建议格式"[商品名称]第二份半价"
- **活动时间**: 开始时间 + 结束时间 (精确到分钟)
- **活动预算**: 总预算金额 (元) 或发放张数上限

**可选字段**:
- **活动标签**: 在商品详情页展示的标签 (如"第2份5折")
- **活动说明**: 活动详细规则说明 (500字符以内)
- **推广位置**: 选择展示位置 (商品详情页、购物车、结算页)

#### 折扣规则配置

**核心参数**:
- **第N份**: 指定第几份开始享受折扣 (默认N=2)
  - 例: N=2 表示第2份半价,第1份原价
  - 例: N=3 表示第3份半价,第1、2份原价
- **折扣比例**: 百分比折扣 (如50%表示半价)
  - 常用配置: 50% (半价), 40% (6折), 30% (7折)
- **最大优惠金额**: 单笔订单最高优惠上限 (元)
- **参与计算商品**: 指定哪些商品参与"第N份"计算
  - 选项: 全部商品 / 指定商品 / 指定分类

**折扣计算逻辑**:
```
假设商品A单价20元,设置"第2份半价":
- 购买1份: 实付 20元
- 购买2份: 实付 20 + 10 = 30元 (第2份半价)
- 购买3份: 实付 20 + 10 + 20 = 50元 (只有第2份半价)
- 购买4份: 实付 20 + 10 + 20 + 10 = 60元 (第2、4份半价)

假设商品A单价20元,设置"第3份半价":
- 购买1份: 实付 20元
- 购买2份: 实付 40元
- 购买3份: 实付 20 + 20 + 10 = 50元 (第3份半价)
- 购买4份: 实付 20 + 20 + 10 + 20 = 70元 (只有第3份半价)
```

#### 适用范围配置

**适用商品**:
- **全部商品**: 店内所有在售商品均可参与
- **指定商品**: 选择具体SKU (支持批量选择)
- **指定分类**: 选择商品分类 (如"主食"、"饮品"、"小吃")
- **排除商品**: 指定不参与活动的商品

**适用门店**:
- **全部门店**: 连锁品牌所有门店
- **指定门店**: 选择具体门店 (支持批量选择)
- **门店分组**: 按区域/等级分组 (如"北京区域"、"旗舰店")

**适用渠道**:
- **堂食**: 门店堂食订单
- **外卖**: 美团外卖/饿了么订单
- **自取**: 到店自取订单
- **全渠道**: 所有渠道

#### 使用限制配置

**用户限制**:
- **每人限领**: 每个用户最多领取N张 (0表示不限)
- **每人限用**: 每个用户最多使用N张 (0表示不限)
- **新用户专享**: 仅限首次下单用户
- **会员等级**: 指定会员等级可用 (普通会员/银卡/金卡等)

**订单限制**:
- **每单限用**: 每笔订单最多使用N张优惠券
- **最低消费**: 订单金额满N元可用
- **最高优惠**: 单笔订单最高优惠N元
- **不可叠加**: 不可与其他优惠券/活动叠加使用

**数量限制**:
- **最少购买数量**: 至少购买N件才能享受折扣
  - 例: 设置N=2时,必须购买≥2件商品
- **最多优惠数量**: 最多N件商品享受折扣
  - 例: 设置N=2时,最多2件商品享受第N份折扣

**时间限制**:
- **可用时段**: 指定时间段内可用 (如"周末专享"、"午市特惠")
- **有效期**: 优惠券领取后N天内有效
- **提前预约**: 需提前N小时预约

### 3. 展示与推广配置

**活动标签配置**:
- **商品详情页标签**: "第2份5折"、"多买多省"
- **购物车提示**: "再买1份立享半价"
- **结算页提示**: "已优惠XX元"

**推广文案配置**:
- **活动标题**: 吸引用户点击的短文案 (20字符以内)
  - 示例: "第二份半价,多买多省"
- **活动副标题**: 补充说明 (50字符以内)
  - 示例: "精选商品参与,每单最高优惠50元"
- **详细规则**: 完整的活动规则说明 (500字符以内)

**推广位置配置**:
- **首页banner**: 店铺首页轮播图
- **分类页推荐**: 商品分类页顶部推荐位
- **商品详情页**: 商品价格下方优惠标签
- **购物车**: 购物车页面优惠提示
- **结算页**: 订单结算页优惠信息

## 快速开始

### 基础用法

```python
from scripts.coupon_generator import SecondHalfPriceCouponGenerator

# 初始化生成器
generator = SecondHalfPriceCouponGenerator()

# 方式1: 自然语言输入
result = generator.create_from_text(
    text="""
    创建"招牌麻辣牛肉"第二份半价活动:
    - 活动时间: 2025-01-10 至 2025-01-20
    - 第2份享受50%折扣
    - 仅限堂食和外卖
    - 每人限用3张
    - 订单满50元可用
    """,
    project_name="新品推广活动"  # 项目名称(必填)
)

# 方式2: 结构化数据输入
config = {
    "activity_name": "招牌麻辣牛肉第二份半价",
    "activity_time": {
        "start": "2025-01-10 00:00",
        "end": "2025-01-20 23:59"
    },
    "discount_rule": {
        "nth_item": 2,  # 第2份
        "discount_rate": 50,  # 50%折扣
        "max_discount_amount": 30  # 单笔最高优惠30元
    },
    "applicable_scope": {
        "products": ["招牌麻辣牛肉", "特色酸菜鱼"],  # 指定商品
        "stores": "all",  # 全部门店
        "channels": ["堂食", "外卖"]  # 堂食+外卖
    },
    "usage_limits": {
        "per_user_limit": 3,  # 每人限用3张
        "per_order_limit": 1,  # 每单限用1张
        "min_order_amount": 50  # 满50元可用
    }
}
result = generator.create_from_dict(
    config=config,
    project_name="新品推广活动"
)

# 方式3: 批量创建
batch_configs = [
    {
        "activity_name": "A商品第二份半价",
        "discount_rule": {"nth_item": 2, "discount_rate": 50},
        # ... 其他配置
    },
    {
        "activity_name": "B商品第三份半价",
        "discount_rule": {"nth_item": 3, "discount_rate": 50},
        # ... 其他配置
    }
]
results = generator.create_batch(
    batch_configs=batch_configs,
    project_name="批量优惠券创建"
)
```

### Layer 3: 执行层 (Python脚本)

**核心执行引擎**:
- `scripts/coupon_generator.py` - 主生成器
- `scripts/parsers/coupon_text_parser.py` - 自然语言解析
- `scripts/validators/coupon_validator.py` - 配置验证器
- `scripts/generators/meituan_config_generator.py` - 美团配置生成器
- `scripts/generators/operation_guide_generator.py` - 操作指南生成器

**执行步骤**:

1. **Step 1: 信息解析与结构化**
   - 调用 `coupon_text_parser.py` 或直接接收结构化数据
   - 提取活动信息、折扣规则、适用范围、使用限制等

2. **Step 2: 配置验证**
   - 调用 `coupon_validator.py`
   - 验证必填字段完整性
   - 检查规则合规性 (如折扣率范围、时间逻辑等)
   - 验证商品/门店是否存在 (可选)

3. **Step 3: 美团配置生成**
   - 调用 `meituan_config_generator.py`
   - 按照美团后台表单结构组织数据
   - 生成JSON格式的配置文件

4. **Step 4: 操作指南生成**
   - 调用 `operation_guide_generator.py`
   - 生成Markdown格式的后台操作步骤
   - 包含截图标注和注意事项

5. **Step 5: 结果输出**
   - 保存配置文件到标准输出路径
   - 生成执行日志和元数据

## 美团后台操作流程

### 创建入口

1. 登录美团管家后台

| 字段名称 | 必填 | 说明 | 示例 |

| 字段名称 | 必填 | 说明 | 示例 |

    │   ├─ 折扣率范围 (1-99)

    ↓

### 规则合规性检查

**检查项**:
- ✅ 时间逻辑: 开始时间 < 结束时间
- ✅ 折扣率范围: 1% ≤ 折扣率 ≤ 99%
- ✅ 金额范围: 最低消费 > 0,最高优惠 > 0
- ✅ 数量范围: 第N份 ≥ 2,最少购买数量 ≥ 第N份
- ✅ 逻辑一致性: 若设置"第3份半价",则"最少购买数量"至少为3

## 注意事项

### 1. 美团后台版本差异

**问题**: 不同区域/版本的美团后台表单字段可能有差异

**建议**:
- 生成配置文件后,手动核对后台实际字段
- 遇到字段缺失/多余时,参考操作指南手动调整
- 定期同步最新的美团后台规范

### 2. 折扣计算逻辑验证

**问题**: 复杂场景下折扣计算可能有歧义

**建议**:
- 使用配置预览功能,模拟购买流程
- 重点验证:
  - 多SKU混合购买时的折扣计算
  - 达到"最高优惠金额"上限时的处理
  - 与其他优惠叠加使用时的优先级

### 3. 批量创建性能

**问题**: 批量创建100+优惠券时性能较慢

**建议**:
- 使用分批处理 (每批20个)
- 启用并行执行 (最多5个并行任务)
- 失败任务自动重试 (最多3次)

### 4. 活动预算控制

**问题**: 预算设置不当可能导致活动提前结束或超支

**建议**:
- 根据历史数据预估活动预算
- 设置预算预警 (达到80%时提醒)
- 实时监控优惠券使用情况

### 5. 商品范围选择策略

**问题**: 全部商品 vs 指定商品,如何选择

**建议**:
- **全部商品**: 适合全店促销,操作简单,但可能影响利润率
- **指定商品**: 适合精准营销,可控性强,但配置复杂
- **指定分类**: 适合分类促销,平衡灵活性和可控性

**典型策略**:
```
新品推广 → 指定商品 (仅新品)
节假日促销 → 指定分类 (主食+饮品)
清库存 → 指定商品 (库存积压商品)
提升客单价 → 全部商品 (刺激凑单)
```
