# 礼品券创建技能包 (Gift Coupon Creator)

## 概述

这是一个**标准操作流程(SOP)型技能包**,用于自动化创建符合美团管家营销中心标准的"礼品券"活动。遵循**三层架构模式**,支持单个和批量创建,能够智能解析自然语言描述或结构化数据,生成标准化的礼品券配置文件,并提供详细的操作指引。

**业务目标**: 通过礼品券活动提升用户参与度和复购率,支持实物礼品兑换场景(如积分兑换、会员福利等)。

**适用场景**:
- ✅ 会员积分兑换礼品
- ✅ 节假日礼品赠送活动
- ✅ 新客注册礼包
- ✅ 活动奖品发放
- ✅ 品牌联名礼品推广

## 核心能力

### 1. 礼品券活动类型

**核心特点**:
- 用户通过券兑换实物礼品(非折扣/代金券)
- 支持单一礼品或多选礼品模式
- 礼品库存独立管理
- 支持兑换条件限制(消费门槛、用户限制等)

**与其他券类型的区别**:
| 特性 | 礼品券 | 满减券 | 折扣券 | 代金券 |
|------|--------|--------|--------|--------|
| 使用方式 | 兑换实物礼品 | 满额减免 | 按比例折扣 | 直接抵扣 |
| 库存管理 | 礼品库存 | 无 | 无 | 无 |
| 兑换流程 | 需选择礼品 | 自动计算 | 自动计算 | 自动计算 |
| 适用场景 | 会员福利、活动奖品 | 促销活动 | 促销活动 | 充值赠送 |

### 2. 多源信息解析

**支持输入格式**:
- ✅ 自然语言描述 (中文)
- ✅ 结构化数据 (JSON/YAML)
- ✅ 批量配置文件 (Excel/CSV)

**智能提取能力**:
- 活动基本信息 (名称、时间、类型)
- 礼品规则 (礼品列表、兑换条件、库存)
- 使用限制 (用户限制、订单限制、地域限制)
- 推广设置 (券样式、使用说明)

### 3. 礼品券配置生成

**输出内容**:
- ✅ 完整的活动配置文件 (JSON格式)
- ✅ 美团管家后台操作步骤说明 (Markdown)
- ✅ 礼品库存管理表格 (Excel)
- ✅ 活动效果预估报告 (可选)

## 快速开始

### 基础用法

```python
from scripts.gift_coupon_generator import GiftCouponGenerator

# 初始化生成器
generator = GiftCouponGenerator()

# 方式1: 自然语言输入
result = generator.create_from_text(
    text="""
    创建"会员专属礼品兑换"活动:
    - 活动时间: 2025年1月15日至2月15日
    - 礼品选项:
      1. 品牌保温杯 (库存500个)
      2. 精美餐具套装 (库存300套)
      3. 限量定制围裙 (库存200件)
    - 兑换条件: 会员等级≥黄金,单笔消费≥199元
    - 每人限兑1次
    """,
    project_name="2025春节会员福利"  # 项目名称(必填)
)

# 方式2: 结构化数据输入
data = {
    "activity_name": "会员专属礼品兑换",
    "activity_period": {
        "start_date": "2025-01-15",
        "end_date": "2025-02-15"
    },
    "gifts": [
        {
            "gift_name": "品牌保温杯",
            "gift_code": "GIFT001",
            "stock": 500,
            "cost_points": 1000  # 如使用积分兑换
        },
        {
            "gift_name": "精美餐具套装",
            "gift_code": "GIFT002",
            "stock": 300,
            "cost_points": 1500
        }
    ],
    "redemption_rules": {
        "member_level": "黄金会员及以上",
        "min_order_amount": 199,
        "max_redemptions_per_user": 1
    }
}
result = generator.create_from_dict(
    data=data,
    project_name="2025春节会员福利"
)

# 方式3: 批量创建
batch_data = [
    {"activity_name": "新客注册礼包", "gifts": [...]},
    {"activity_name": "生日会员专享", "gifts": [...]},
    {"activity_name": "节日特惠礼品", "gifts": [...]}
]
results = generator.create_batch(
    batch_data=batch_data,
    project_name="2025Q1营销活动"
)
```

### Layer 3: 执行层 (Python脚本)

**核心执行引擎**:
- `scripts/gift_coupon_generator.py` - 主生成器
- `scripts/parsers/text_parser.py` - 自然语言解析
- `scripts/validators/field_validator.py` - 字段验证
- `scripts/generators/config_generator.py` - 配置文件生成器
- `scripts/generators/guide_generator.py` - 操作指南生成器
- `scripts/generators/inventory_generator.py` - 库存表生成器

**执行步骤**:

1. **Step 1: 信息解析与结构化**
   - 调用 `text_parser.py` 或直接接收结构化数据
   - 提取活动信息、礼品列表、兑换规则、使用限制等

2. **Step 2: 字段验证**
   - 调用 `field_validator.py`
   - 验证必填字段完整性
   - 验证礼品库存数量合理性
   - 验证时间逻辑正确性

3. **Step 3: 配置文件生成**
   - 调用 `config_generator.py`
   - 按照美团管家后台标准格式组织数据
   - 生成JSON配置文件

4. **Step 4: 操作指南生成**
   - 调用 `guide_generator.py`
   - 生成详细的后台操作步骤说明(Markdown格式)
   - 包含字段填写说明和注意事项

5. **Step 5: 礼品库存表生成**
   - 调用 `inventory_generator.py`
   - 使用 `openpyxl` 生成Excel库存管理表
   - 包含礼品信息、库存数量、兑换记录等

6. **Step 6: 效果预估报告(可选)**
   - 基于历史数据预估活动效果
   - 包含预期参与人数、兑换率、成本预算等

## 质量保障

### 必填字段验证

**验证规则**:
```python
REQUIRED_FIELDS = {
    "activity": ["activity_name", "activity_type", "activity_period", "channel"],
    "gift": ["gift_name", "gift_code", "gift_image", "gift_stock", "gift_description"],
    "redemption": ["redemption_mode", "validity_period"],
    "usage": ["max_receive_per_user", "max_use_per_user"],
    "coupon_style": ["coupon_name", "coupon_icon", "background_color", "usage_instructions"]
}
```

### 礼品库存合理性检查

**检查规则**:
- 库存数量 > 0
- 每日限量 ≤ 总库存
- 库存预警阈值 < 总库存
- 兑换条件与库存匹配(避免库存不足)

### 时间逻辑正确性检查

**检查规则**:
- 活动开始时间 < 活动结束时间
- 活动开始时间 ≥ 当前时间(创建时)
- 券有效期 > 0
- 可用时段时间段合法(开始时间 < 结束时间)

### 限制条件冲突检查

**检查规则**:
- 新客专享 与 会员等级限制 不能同时设置
- 每人限领 ≥ 每人限用
- 最低消费门槛 与 积分门槛 至少设置一项

## 注意事项

### 1. 礼品图片规范

**问题**: 图片尺寸或格式不符合美团管家要求

**建议**:
- 建议尺寸: 750x750px (1:1比例)
- 支持格式: JPG, PNG
- 文件大小: <500KB
- 图片清晰,突出礼品特点

### 2. 礼品库存管理

**问题**: 库存设置不合理导致兑换失败

**建议**:
- 预留安全库存(实际库存 × 1.2)
- 设置库存预警阈值(建议总库存的10%)
- 定期同步实际库存数据
- 兑换高峰期实时监控库存

### 3. 兑换条件设置

**问题**: 兑换条件过于复杂或矛盾

**建议**:
- 兑换条件简单明了,用户易理解
- 避免多重条件叠加(如消费门槛 + 积分门槛 + 会员限制)
- 测试兑换流程,确保用户可顺利兑换

### 4. 活动时间规划

**问题**: 活动时间设置不合理

**建议**:
- 活动周期建议15-30天(过短影响参与,过长影响紧迫感)
- 券有效期建议7-30天
- 避免活动时间与其他大型促销冲突
- 考虑节假日和周末的用户活跃度

### 5. 成本控制

**问题**: 礼品成本超出预算

**建议**:
- 提前核算总成本 = 礼品成本 × 预估兑换率
- 设置单用户兑换上限
- 选择性价比高的礼品
- 监控实时兑换情况,必要时调整库存

### 6. 用户体验优化

**问题**: 兑换流程复杂,用户放弃兑换

**建议**:
- 简化兑换流程(最多3步)
- 提供清晰的兑换说明
- 礼品图片和描述详细准确
- 提供客服联系方式,解答用户疑问
