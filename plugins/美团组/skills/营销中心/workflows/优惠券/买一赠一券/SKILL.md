# 买一赠一券创建技能包 (BOGO Coupon Creator)

## 概述

这是一个**标准操作流程(SOP)型技能包**,用于在美团管家后台创建"买一赠一券"(Buy One Get One)优惠券。遵循**三层架构模式**,支持单个和批量创建,能够智能解析活动需求,自动生成符合美团规范的优惠券配置文件,并提供完整的表单字段填写指南。

**业务目标**:
- 🎯 提升客单价和复购率
- 🎯 清理库存或推广新品
- 🎯 提高客户满意度和到店率
- 🎯 配合节假日和营销活动

**适用场景**:
- ✅ 同品赠送 (买1份火锅底料送1份火锅底料)
- ✅ 指定商品赠送 (买1份主菜送1份小吃)
- ✅ 节假日促销 (国庆/春节/店庆)
- ✅ 新品推广 (买老品送新品试吃)
- ✅ 库存清理 (买正价品送临期商品)

## 核心能力

### 1. 多种赠送规则支持

**规则类型**:

#### 规则1: 同品赠送
- **定义**: 购买指定商品1份,赠送同款商品1份
- **示例**: 买1份麻辣牛肉锅底,送1份麻辣牛肉锅底
- **适用场景**: 推广爆款菜品、提高单品销量

#### 规则2: 指定商品赠送
- **定义**: 购买指定商品A,赠送指定商品B
- **示例**: 买1份招牌火锅,送1份酸梅汁
- **适用场景**: 组合营销、带动低销量商品、清库存

#### 规则3: 分类赠送
- **定义**: 购买指定分类商品,赠送该分类下任意商品
- **示例**: 买1份锅底分类商品,送1份锅底分类任意商品
- **适用场景**: 促销整个品类、灵活赠送

### 2. 灵活的使用限制

**限制维度**:
- ✅ **使用时间**: 指定活动开始/结束时间,支持每日时段限制
- ✅ **使用次数**: 每人每天限领N次,每人总限领N次
- ✅ **适用门店**: 指定参与门店,支持多门店联动
- ✅ **适用渠道**: 仅限堂食/仅限外卖/堂食外卖均可
- ✅ **适用商品**: 白名单(仅限指定商品)或黑名单(排除指定商品)
- ✅ **叠加规则**: 是否可与其他优惠叠加使用

### 3. 库存和成本控制

**控制能力**:
- ✅ **总库存限制**: 限制活动期间总发放量
- ✅ **单日库存**: 每日可发放数量上限
- ✅ **实时监控**: 库存消耗实时统计
- ✅ **自动下架**: 库存用尽自动停止发放
- ✅ **成本预估**: 根据客单价和发放量预估活动成本

### 4. 智能配置生成

**输入方式**:
- ✅ 自然语言描述 (中文/英文)
- ✅ 结构化数据 (JSON/Excel)
- ✅ 活动模板快速复制

**智能推断**:
- 根据商品价格自动推荐库存设置
- 根据历史活动数据推荐使用限制
- 根据节假日自动推荐活动时间

## 快速开始

### 基础用法

```python
from scripts.bogo_coupon_generator import BOGOCouponGenerator

# 初始化生成器
generator = BOGOCouponGenerator()

# 方式1: 自然语言输入
result = generator.create_from_text(
    text="""
    请创建一个买一赠一券活动:
    - 活动名称: 国庆火锅狂欢周
    - 购买商品: 麻辣牛肉火锅底料
    - 赠送商品: 同款商品
    - 活动时间: 2025年10月1日-10月7日
    - 总库存: 500张
    - 每人每天限领1张
    - 仅限堂食使用
    """,
    project_name="国庆营销活动"  # 项目名称(必填)
)

# 方式2: 结构化数据输入
data = {
    "coupon_name": "国庆火锅狂欢周",
    "coupon_type": "bogo_same_item",  # 同品赠送
    "purchase_item": {
        "item_name": "麻辣牛肉火锅底料",
        "item_id": "SPU12345"
    },
    "gift_item": {
        "item_name": "麻辣牛肉火锅底料",
        "item_id": "SPU12345"
    },
    "validity_period": {
        "start_time": "2025-10-01 00:00:00",
        "end_time": "2025-10-07 23:59:59"
    },
    "usage_limits": {
        "total_stock": 500,
        "daily_stock": 100,
        "user_daily_limit": 1,
        "user_total_limit": 3
    },
    "applicable_channels": ["dine_in"],  # 堂食
    "applicable_stores": ["店铺A", "店铺B"]
}
result = generator.create_from_dict(
    data=data,
    project_name="国庆营销活动"
)

# 方式3: 批量创建
batch_data = [
    {"coupon_name": "国庆火锅狂欢周", ...},
    {"coupon_name": "中秋团圆宴", ...},
    {"coupon_name": "春节新品尝鲜", ...}
]
results = generator.create_batch(
    batch_data=batch_data,
    project_name="2025Q4营销活动"
)
```

## 创建流程

### 美团管家后台操作步骤

#### 第一步: 进入优惠券管理

**路径**: 美团管家 → 营销中心 → 优惠券管理 → 创建优惠券

**操作**:
1. 登录美团管家后台
2. 点击左侧菜单"营销中心"
3. 选择"优惠券管理"
4. 点击右上角"创建优惠券"按钮
5. 选择"买一赠一券"类型

#### 第二步: 基本信息配置

**表单字段** (8个必填字段):

| 字段编号 | 字段名称 | 必填 | 说明 | 示例值 |
|---------|---------|------|------|--------|
| 1 | 优惠券名称 | ✅ | 活动名称,显示在用户端 | "国庆火锅狂欢周" |
| 2 | 优惠券描述 | ✅ | 活动详细说明,显示在领取页面 | "买1份火锅底料送1份同款" |
| 3 | 活动开始时间 | ✅ | 格式: YYYY-MM-DD HH:MM:SS | "2025-10-01 00:00:00" |
| 4 | 活动结束时间 | ✅ | 格式: YYYY-MM-DD HH:MM:SS | "2025-10-07 23:59:59" |
| 5 | 优惠券图片 | ❌ | 建议尺寸: 750x300px | 上传图片文件 |
| 6 | 适用门店 | ✅ | 多选下拉框 | ["店铺A", "店铺B"] |
| 7 | 适用渠道 | ✅ | 单选: 堂食/外卖/全部 | "堂食" |
| 8 | 券码类型 | ✅ | 单选: 系统生成/自定义 | "系统生成" |

**填写技巧**:
- 优惠券名称: 简洁有力,突出"买一赠一"关键词
- 优惠券描述: 清晰说明购买商品和赠送商品,避免歧义
- 活动时间: 建议与节假日/营销节点对齐
- 适用门店: 优先选择客流量大的门店

- **使用时段**: 可设置为高峰时段或低峰时段,根据营销目标调整
- **券有效期**: 建议7-14天,过短影响使用率,过长影响紧迫感

**核心执行引擎**:
- `scripts/bogo_coupon_generator.py` - 主生成器
- `scripts/parsers/coupon_parser.py` - 需求解析
- `scripts/validators/config_validator.py` - 配置验证
- `scripts/generators/guide_generator.py` - 操作指南生成器
- `scripts/integrations/meituan_api.py` - 美团API集成 (可选)

**执行步骤**:

1. **Step 1: 需求解析与结构化**
   - 调用 `coupon_parser.py` 解析自然语言或结构化数据
   - 提取活动名称、赠送规则、使用限制等信息

2. **Step 2: 配置验证**
   - 调用 `config_validator.py`
   - 验证必填字段完整性
   - 验证库存和限制设置合理性
   - 验证商品ID存在性

3. **Step 3: 配置文件生成**
   - 组织为JSON配置结构
   - 符合美团API规范 (如集成API)
   - 保存到标准输出路径

4. **Step 4: 操作指南生成**
   - 调用 `guide_generator.py`
   - 生成Markdown格式操作指南
   - 包含所有表单字段填写说明
   - 包含截图和注意事项

5. **Step 5: API集成 (可选)**
   - 调用 `meituan_api.py`
   - 直接通过API创建优惠券
   - 返回优惠券ID和链接

## 执行流程图

## 使用场景

### 场景1: 国庆节同品赠送活动

**需求**: 国庆期间推广爆款火锅底料

**输入**:
```python
generator.create_from_text(
    text="""
    创建国庆买一赠一券:
    - 活动名称: 国庆火锅狂欢周
    - 购买商品: 麻辣牛肉火锅底料
    - 赠送商品: 同款商品
    - 活动时间: 10月1日-10月7日
    - 总库存: 1000张
    - 每人每天限领1张,总限领3张
    - 仅限堂食
    """,
    project_name="2025国庆营销"
)
```

**输出**:
- `output/2025国庆营销/bogo-coupon/买一赠一券配置_国庆火锅狂欢周_YYYYMMDD_HHMMSS.json`
- `output/2025国庆营销/bogo-coupon/操作指南_国庆火锅狂欢周_YYYYMMDD_HHMMSS.md`

### 场景2: 新品推广指定商品赠送

**需求**: 推广新品酸菜鱼,买主菜送新品

**输入**:
```python
data = {
    "coupon_name": "新品酸菜鱼尝鲜周",
    "coupon_type": "bogo_specified_item",
    "purchase_item": {
        "item_name": "招牌火锅套餐",
        "item_id": "SPU001"
    },
    "gift_item": {
        "item_name": "酸菜鱼",
        "item_id": "SPU999",
        "stock": 300
    },
    "validity_period": {
        "start_time": "2025-11-01 00:00:00",
        "end_time": "2025-11-07 23:59:59"
    }
}
generator.create_from_dict(data, project_name="新品推广")
```

**输出**:
- `output/新品推广/bogo-coupon/买一赠一券配置_新品酸菜鱼尝鲜周_YYYYMMDD_HHMMSS.json`

### 场景3: 批量创建节假日活动

**需求**: 一次性创建春节/元宵/清明3个活动

**输入**:
```python
batch_data = [
    {"coupon_name": "春节买一送一", "start_time": "2025-01-25", ...},
    {"coupon_name": "元宵买一送一", "start_time": "2025-02-09", ...},
    {"coupon_name": "清明买一送一", "start_time": "2025-04-04", ...}
]
generator.create_batch(batch_data, project_name="2025节假日营销")
```

**输出**:
- `output/2025节假日营销/bogo-coupon/批量配置_YYYYMMDD_HHMMSS.json`

## 质量保障

### 必填字段验证

**验证规则**:
```python
REQUIRED_FIELDS = {
    "basic_info": ["coupon_name", "coupon_description", "start_time", "end_time", "applicable_stores", "applicable_channels"],
    "gift_rule": ["rule_type", "purchase_item", "gift_item"],
    "usage_limits": ["total_stock", "user_daily_claim_limit", "user_total_claim_limit"]
}
```

### 配置合理性验证

**验证项**:
- ✅ 库存设置: 总库存 > 每日库存 × 活动天数
- ✅ 时间有效性: 结束时间 > 开始时间
- ✅ 商品ID存在性: 购买商品和赠送商品ID必须存在于商品库
- ✅ 限制一致性: 领取限制 ≥ 使用限制

### 操作指南完整性

**质量标准**:
- ✅ 包含所有31个表单字段的填写说明
- ✅ 提供示例值和注意事项
- ✅ 包含预览检查清单
- ✅ 提供错误处理建议

## 注意事项

### 1. 库存控制策略

**问题**: 总库存如何分配到每日库存

**建议**:
- 活动前3天: 每日库存 = 总库存 × 30%
- 活动中期: 每日库存 = 总库存 × 40%
- 活动后期: 每日库存 = 总库存 × 30%
- 预留10%应急库存

### 2. 赠送商品成本控制

**问题**: 如何控制活动成本

**建议**:
- 同品赠送: 选择成本较低的商品
- 指定商品赠送: 赠送利润较高的商品或库存积压商品
- 分类赠送: 限制高价商品赠送数量

### 3. 用户体验优化

**问题**: 如何提高优惠券使用率

**建议**:
- 优惠券名称: 简洁直接,突出"买一赠一"
- 有效期: 建议7-14天,过短影响使用率
- 使用时段: 避免仅限低峰时段,影响用户体验
- 叠加规则: 允许与部分优惠叠加,提高吸引力

### 4. 活动效果监控

**问题**: 如何评估活动效果

**建议**:
- 监控指标: 领取率、使用率、客单价提升、复购率
- 实时监控: 每日库存消耗、用户反馈
- 数据分析: 活动结束后生成完整分析报告

### 5. 商品选择策略

**问题**: 如何选择购买商品和赠送商品

**建议**:
- **购买商品**: 选择高客单价或高利润商品
- **赠送商品** (同品): 选择成本较低但用户价值高的商品
- **赠送商品** (指定): 选择库存积压或新品推广商品
- **避免**: 特价商品、酒水等低利润商品
