# 代金券创建技能包 (Cash Coupon Creator)

## 概述

这是一个**标准操作流程(SOP)型技能包**,用于自动化指导在美团管家后台创建"代金券"类型的优惠券活动。遵循**三层架构模式**,支持单个和批量创建,能够智能解析活动需求,生成标准化的配置参数,确保优惠券活动符合业务规范和营销目标。

**业务目标**:
- 提升订单转化率和客单价
- 吸引新客户和激活老客户
- 配合营销活动实现促销目标
- 标准化优惠券创建流程,减少人工错误

**适用场景**:
- ✅ 节假日促销活动 (春节、国庆、双11等)
- ✅ 新客拉新活动 (首单立减、新人专享)
- ✅ 会员权益活动 (会员专享券)
- ✅ 满减促销活动 (满100减20)
- ✅ 品类/单品推广 (特定菜品优惠)
- ✅ 时段营销活动 (午市特惠、夜宵券)

## 核心能力

### 1. 代金券业务特性

**核心功能**:
- **抵扣金额**: 直接抵扣订单金额(如立减20元)
- **满减条件**: 可设置最低消费门槛(如满100减20)
- **无门槛券**: 支持直接抵扣,无需满减条件
- **适用范围**: 可限定商品、门店、渠道
- **用户限制**: 可限定用户类型(新客/老客/会员)

**代金券类型**:
1. **无门槛券**: 直接抵扣,适合新客拉新
2. **满减券**: 设置消费门槛,适合提升客单价
3. **品类券**: 限定商品品类,适合品类推广
4. **单品券**: 限定具体商品,适合爆品营销
5. **时段券**: 限定使用时段,适合错峰营销

### 2. 创建流程自动化

**支持输入格式**:
- ✅ 自然语言描述 (中文/英文)
- ✅ 结构化数据 (JSON/YAML)
- ✅ Excel批量配置表
- ✅ 活动方案文档

**智能提取能力**:
- 活动名称和主题
- 抵扣金额和满减条件
- 发放数量和领取限制
- 适用范围和使用限制
- 时间范围和有效期

### 3. 配置参数生成

**基于美团管家后台标准**:
- 自动生成完整的表单配置
- 参数合规性验证
- 冲突规则检查
- 最佳实践建议

## 快速开始

### 基础用法

```python
from scripts.cash_coupon_generator import CashCouponGenerator

# 初始化生成器
generator = CashCouponGenerator()

# 方式1: 自然语言输入
result = generator.create_from_text(
    text="""
    创建一个春节促销代金券:
    - 活动名称: 春节满减活动
    - 抵扣金额: 20元
    - 满减条件: 满100元可用
    - 发放数量: 1000张
    - 每人限领: 1张
    - 有效期: 2025-01-20 至 2025-02-10
    - 适用门店: 全部门店
    """,
    project_name="2025春节营销活动"  # 项目名称(必填)
)

# 方式2: 结构化数据输入
data = {
    "activity_name": "春节满减活动",
    "coupon_amount": 20,
    "minimum_amount": 100,
    "total_quantity": 1000,
    "per_user_limit": 1,
    "valid_from": "2025-01-20",
    "valid_to": "2025-02-10",
    "applicable_stores": "all"
}
result = generator.create_from_dict(
    data=data,
    project_name="2025春节营销活动"
)

# 方式3: 批量创建
batch_data = [
    {"activity_name": "新客首单立减", "coupon_amount": 10, ...},
    {"activity_name": "会员专享券", "coupon_amount": 15, ...},
    {"activity_name": "午市特惠券", "coupon_amount": 5, ...}
]
results = generator.create_batch(
    batch_data=batch_data,
    project_name="2025Q1营销活动矩阵"
)
```

## 创建流程 (美团管家后台)

### 第一步: 进入创建页面

**操作路径**:
```
美团管家后台 → 营销中心 → 优惠券 → 创建优惠券 → 选择"代金券"
```

### 第二步: 填写活动基本信息

#### 2.1 活动名称 ⭐

**字段说明**:
- **必填**: ✅
- **字段名**: 活动名称
- **格式**: 文本,最多30个字符
- **示例**: "春节满减活动"、"新客首单立减"、"会员专享券"

**填写建议**:
- 包含活动主题和时间范围
- 清晰表达优惠力度
- 便于后期查找和管理

**配置示例**:
```json
{
  "activity_name": "春节满减活动"
}
```

#### 2.2 活动时间

**字段说明**:
- **必填**: ✅
- **字段名**: 活动开始时间、活动结束时间
- **格式**: 日期时间选择器
- **说明**: 活动时间范围,用户可在此期间领取优惠券

**填写建议**:
- 提前1-3天开始活动(预热期)
- 活动结束时间留出使用缓冲期
- 重大节日活动建议跨度7-15天

**配置示例**:
```json
{
  "activity_period": {
    "start_time": "2025-01-20 00:00:00",
    "end_time": "2025-02-10 23:59:59"
  }
}
```

### 第三步: 配置抵扣规则 ⭐⭐⭐

#### 3.1 抵扣金额 ⭐

**字段说明**:
- **必填**: ✅
- **字段名**: 抵扣金额
- **格式**: 数值,单位:元
- **范围**: 1-500元
- **示例**: 10、20、50

**填写建议**:
- 新客拉新: 10-20元
- 满减促销: 根据客单价设置(如满100减20)
- 会员权益: 15-30元
- 爆品营销: 5-15元

**配置示例**:
```json
{
  "discount_rules": {
    "coupon_amount": 20
  }
}
```

#### 3.2 满减条件

**字段说明**:
- **必填**: ❌ (可选,不填则为无门槛券)
- **字段名**: 最低消费金额
- **格式**: 数值,单位:元
- **范围**: 抵扣金额+1元 至 10000元
- **示例**: 50、100、200

**常见配置**:
| 优惠券类型 | 抵扣金额 | 满减条件 | 折扣率 |
|-----------|---------|---------|--------|
| 无门槛券 | 10元 | 无 | - |
| 低门槛券 | 10元 | 满50元 | 20% |
| 标准满减 | 20元 | 满100元 | 20% |
| 高价满减 | 50元 | 满300元 | 16.7% |
| 超值满减 | 100元 | 满500元 | 20% |

**填写建议**:
- 折扣率建议控制在15%-25%
- 满减门槛 = 抵扣金额 × 4-6倍
- 新客拉新可不设门槛或低门槛
- 提升客单价需设置合理门槛

**配置示例**:
```json
{
  "discount_rules": {
    "coupon_amount": 20,
    "minimum_amount": 100,
    "discount_rate": "20%"
  }
}
```

### 第四步: 设置发放和领取规则

#### 4.1 发放数量 ⭐

**字段说明**:
- **必填**: ✅
- **字段名**: 发放总量
- **格式**: 整数
- **范围**: 1-999999
- **示例**: 100、500、1000

**填写建议**:
- 测试活动: 50-100张
- 小型活动: 200-500张
- 中型活动: 500-2000张
- 大型活动: 2000-10000张
- 根据预算和门店接待能力设置

**配置示例**:
```json
{
  "distribution_rules": {
    "total_quantity": 1000
  }
}
```

#### 4.2 每人限领 ⭐

**字段说明**:
- **必填**: ✅
- **字段名**: 每人限领数量
- **格式**: 整数
- **范围**: 1-10
- **示例**: 1、2、3

**常见配置**:
| 活动类型 | 限领数量 | 说明 |
|---------|---------|------|
| 新客拉新 | 1张 | 确保更多新客参与 |
| 会员权益 | 2-3张 | 提升会员忠诚度 |
| 促销活动 | 1-2张 | 平衡参与度和成本 |
| 品类推广 | 1张 | 专项推广 |

**填写建议**:
- 大额券(≥50元): 限领1张
- 中额券(20-50元): 限领1-2张
- 小额券(≤20元): 限领2-3张
- 根据预算和用户覆盖度权衡

**配置示例**:
```json
{
  "distribution_rules": {
    "total_quantity": 1000,
    "per_user_limit": 1
  }
}
```

#### 4.3 领取方式

**字段说明**:
- **必填**: ✅
- **字段名**: 领取方式
- **选项**: 手动领取、自动发放、活动页领取
- **默认**: 手动领取

**选项说明**:
1. **手动领取**: 用户主动点击领取(推荐)
2. **自动发放**: 满足条件自动发放(精准营销)
3. **活动页领取**: 通过活动页面领取(配合宣传)

**配置示例**:
```json
{
  "distribution_rules": {
    "receive_method": "manual",
    "auto_send_conditions": null
  }
}
```

### 第五步: 设置适用范围

#### 5.1 适用门店 ⭐

**字段说明**:
- **必填**: ✅
- **字段名**: 适用门店
- **选项**: 全部门店、指定门店、门店分组
- **默认**: 全部门店

**选项说明**:
1. **全部门店**: 所有门店通用(推荐用于品牌级活动)
2. **指定门店**: 选择特定门店(如新开店、低流量店)
3. **门店分组**: 按分组设置(如华东区、华北区)

**配置示例**:
```json
{
  "applicable_scope": {
    "stores": {
      "type": "all",
      "store_ids": [],
      "store_groups": []
    }
  }
}
```

#### 5.2 适用商品 ⭐⭐

**字段说明**:
- **必填**: ❌ (默认全部商品)
- **字段名**: 适用商品范围
- **选项**: 全部商品、指定商品、商品分类
- **默认**: 全部商品

**选项说明**:
1. **全部商品**: 订单内任意商品可用
2. **指定商品**: 限定具体商品(单品推广)
3. **商品分类**: 限定品类(如主食类、饮品类)

**常见配置**:
| 优惠券用途 | 适用商品 | 示例 |
|-----------|---------|------|
| 通用促销 | 全部商品 | 春节满减 |
| 品类推广 | 商品分类 | 火锅类满减 |
| 爆品营销 | 指定商品 | 招牌菜优惠 |
| 新品推广 | 指定商品 | 新品尝鲜券 |

**配置示例**:
```json
{
  "applicable_scope": {
    "products": {
      "type": "all",
      "product_ids": [],
      "category_ids": []
    }
  }
}
```

#### 5.3 适用渠道

**字段说明**:
- **必填**: ❌ (默认全渠道)
- **字段名**: 适用渠道
- **选项**: 全渠道、堂食、外卖、自提
- **默认**: 全渠道

**选项说明**:
1. **全渠道**: 堂食+外卖+自提通用
2. **仅堂食**: 限定到店消费使用
3. **仅外卖**: 限定外卖订单使用
4. **仅自提**: 限定自提订单使用

**配置示例**:
```json
{
  "applicable_scope": {
    "channels": ["dine_in", "takeout", "pickup"]
  }
}
```

### 第六步: 设置使用限制

#### 6.1 有效期设置 ⭐

**字段说明**:
- **必填**: ✅
- **字段名**: 券有效期
- **选项**: 固定日期、领取后N天有效
- **默认**: 固定日期

**选项说明**:
1. **固定日期**: 指定开始和结束日期
   - 适合: 节假日活动、限时促销
2. **领取后N天有效**: 从领取日起计算
   - 适合: 常规营销、会员权益
   - N天范围: 1-90天

**配置示例**:
```json
{
  "validity_rules": {
    "type": "fixed_date",
    "valid_from": "2025-01-20 00:00:00",
    "valid_to": "2025-02-10 23:59:59"
  }
}
```

或

```json
{
  "validity_rules": {
    "type": "days_after_receive",
    "valid_days": 7
  }
}
```

#### 6.2 使用时段限制

**字段说明**:
- **必填**: ❌ (默认全时段)
- **字段名**: 可用时段
- **选项**: 全天、指定时段
- **默认**: 全天

**常见配置**:
| 时段类型 | 时间范围 | 适用场景 |
|---------|---------|---------|
| 全天 | 00:00-23:59 | 通用券 |
| 午市 | 11:00-14:00 | 午市引流 |
| 晚市 | 17:00-21:00 | 晚市高峰 |
| 夜宵 | 21:00-02:00 | 夜宵场景 |
| 非高峰 | 14:00-17:00 | 错峰营销 |

**配置示例**:
```json
{
  "usage_restrictions": {
    "time_slots": [
      {
        "start_time": "11:00",
        "end_time": "14:00"
      }
    ]
  }
}
```

#### 6.3 用户限制

**字段说明**:
- **必填**: ❌ (默认全部用户)
- **字段名**: 用户限制
- **选项**: 全部用户、新客户、老客户、会员
- **默认**: 全部用户

**选项说明**:
1. **全部用户**: 无限制
2. **新客户**: 首单用户(拉新)
3. **老客户**: 历史订单≥1(促活)
4. **会员**: 会员等级用户(权益)

**配置示例**:
```json
{
  "usage_restrictions": {
    "user_type": "all",
    "new_user_only": false,
    "member_level": null
  }
}
```

#### 6.4 叠加使用规则

**字段说明**:
- **必填**: ❌ (默认不可叠加)
- **字段名**: 叠加规则
- **选项**: 不可叠加、可与会员折扣叠加、可与其他优惠叠加
- **默认**: 不可叠加

**选项说明**:
1. **不可叠加**: 订单只能使用一张券(推荐)
2. **可与会员折扣叠加**: 券+会员折扣
3. **可与其他优惠叠加**: 多张券同时使用

**配置示例**:
```json
{
  "usage_restrictions": {
    "stackable": false,
    "stackable_with_member_discount": false,
    "stackable_with_other_coupons": false
  }
}
```

### Layer 3: 执行层 (Python脚本)

**核心执行引擎**:
- `scripts/cash_coupon_generator.py` - 主生成器
- `scripts/parsers/activity_parser.py` - 活动需求解析
- `scripts/validators/config_validator.py` - 配置参数验证
- `scripts/validators/conflict_checker.py` - 冲突规则检查
- `scripts/generators/config_generator.py` - JSON配置生成器

**执行步骤**:

1. **Step 1: 活动需求解析**
   - 调用 `activity_parser.py`
   - 提取活动名称、优惠规则、适用范围等信息

2. **Step 2: 参数合规性验证**
   - 调用 `config_validator.py`
   - 验证必填字段完整性
   - 验证数值范围合法性
   - 验证时间逻辑正确性

3. **Step 3: 冲突规则检查**
   - 调用 `conflict_checker.py`
   - 检查满减条件与抵扣金额是否冲突
   - 检查活动时间与券有效期是否冲突
   - 检查叠加规则与其他配置是否冲突

4. **Step 4: 最佳实践建议**
   - 根据行业经验提供优化建议
   - 标注潜在风险点
   - 推荐配置方案

5. **Step 5: 配置文件生成**
   - 调用 `config_generator.py`
   - 生成标准化的JSON配置文件
   - 保存到标准输出路径

## 注意事项

### 1. 活动时间与券有效期关系

**问题**: 活动时间与券有效期容易混淆

**说明**:
- **活动时间**: 用户可领取优惠券的时间范围
- **券有效期**: 优惠券可使用的时间范围

**建议**:
- 券有效期应 ≥ 活动结束时间(留出使用缓冲期)
- 固定日期券: 有效期设置为活动结束后3-7天
- 领取后N天有效: N天建议≥3天

### 2. 折扣率控制

**问题**: 优惠力度过大导致亏损

**建议**:
- 折扣率建议控制在15%-25%
- 新客拉新可适当提高至30%
- 计算满减条件: 抵扣金额 ÷ 折扣率

### 3. 发放数量与预算

**问题**: 发放数量不合理导致预算超支或浪费

**建议**:
- 总预算 = 抵扣金额 × 发放数量 × 预估核销率
- 预估核销率参考: 新客券30%-40%, 通用券20%-30%, 品类券15%-25%
- 留出10%-20%预算弹性

### 4. 适用范围设置

**问题**: 适用范围过宽或过窄影响效果

**建议**:
- 品牌级活动: 全门店+全商品
- 门店引流: 指定门店+全商品
- 品类推广: 全门店+指定品类
- 爆品营销: 全门店+指定商品

### 5. 用户限制策略

**问题**: 用户限制不当影响活动效果

**建议**:
- 新客拉新: 限定新客户+无门槛/低门槛
- 老客促活: 限定老客户+中等满减
- 会员权益: 限定会员+较高优惠
- 全员促销: 不限用户+标准满减
