# 配送券创建技能包 (Delivery Coupon Creator)

## 概述

这是一个**标准操作流程(SOP)型技能包**,用于自动化创建美团管家后台的配送券活动。遵循**三层架构模式**,支持多种配送优惠类型(满额免配送费、配送费直减等),能够智能解析自然语言描述或结构化数据,生成标准化的配置参数清单,帮助运营人员快速在美团管家后台完成配送券设置。

**业务目标**:
- 降低用户配送成本门槛,提升外卖订单量
- 标准化配送券创建流程,减少人工配置错误
- 支持多场景配送优惠策略(满额免配、定额减免、阶梯优惠等)

**适用场景**:
- ✅ 新店开业期间,吸引首单用户(免配送费)
- ✅ 促销活动期间,降低下单门槛(满额免配送)
- ✅ 特定时段订单激励(午市/晚市配送费减免)
- ✅ 会员专享配送优惠
- ✅ 竞品压制策略(配送费优势)

## 核心能力

### 1. 配送券类型支持

**支持的配送优惠类型**:

| 类型 | 说明 | 使用场景 | 示例 |
|------|------|----------|------|
| **满额免配送费** | 订单满指定金额,配送费全免 | 提升客单价,鼓励凑单 | 满30元免配送费 |
| **配送费直减** | 配送费减免固定金额 | 降低下单门槛,快速拉新 | 配送费减3元 |
| **配送费折扣** | 配送费按比例折扣 | 灵活优惠,适合测试 | 配送费8折 |
| **阶梯配送优惠** | 不同订单金额对应不同减免 | 精细化运营,利润最大化 | 满20减2元,满30减4元 |
| **全场免配送费** | 无门槛免配送费 | 重大促销活动,快速引流 | 全场免配送费 |

### 2. 智能需求解析

**支持输入格式**:
- ✅ 自然语言描述 (中文)
- ✅ 结构化数据 (JSON/Dict)
- ✅ 批量活动配置 (Excel/CSV)
- ✅ 混合格式输入

**智能提取能力**:
- 配送券类型识别
- 优惠规则参数提取(满减金额、减免额度、折扣比例)
- 适用范围解析(全平台/指定门店/会员专享)
- 时间规则提取(有效期、可用时段)
- 使用限制识别(领取次数、使用次数、用户限制)

### 3. 配置参数生成

**基于美团管家后台规范**:
- 自动生成标准化配置参数
- 字段必填项验证
- 数据格式规范化
- 配置冲突检测

**核心处理逻辑**:
1. **需求标准化**: 将自然语言转换为结构化参数
2. **规则验证**: 检查配送优惠规则合理性
3. **范围校验**: 验证适用门店、用户群体等配置
4. **时间冲突检测**: 避免活动时间重叠
5. **输出格式化**: 生成可直接用于后台填写的配置清单

## 快速开始

### 基础用法

```python
from scripts.delivery_coupon_generator import DeliveryCouponGenerator

# 初始化生成器
generator = DeliveryCouponGenerator()

# 方式1: 自然语言输入
result = generator.create_from_text(
    text="""
    创建一个满30元免配送费的优惠券:
    - 活动名称: 新店开业免配送
    - 有效期: 2025-01-10 至 2025-01-20
    - 每个用户限领1张,限用1次
    - 适用门店: 全部门店
    """,
    project_name="新店开业营销活动"  # 项目名称(必填)
)

# 方式2: 结构化数据输入
data = {
    "coupon_name": "午市配送优惠",
    "coupon_type": "满额免配送费",
    "threshold_amount": 25.0,  # 满25元
    "discount_amount": 0,  # 免配送费(减免全额)
    "valid_period": {
        "start_date": "2025-01-15",
        "end_date": "2025-02-15"
    },
    "usage_time": {
        "available_hours": ["11:00-14:00"]  # 仅午市可用
    },
    "user_limits": {
        "receive_limit": 1,  # 每人限领1张
        "usage_limit": 1  # 每人限用1次
    },
    "applicable_stores": "all"  # 全部门店
}
result = generator.create_from_dict(
    data=data,
    project_name="午市配送优惠"
)

# 方式3: 批量创建多个配送券
batch_data = [
    {"coupon_name": "早餐免配送", "coupon_type": "满额免配送费", ...},
    {"coupon_name": "午市配送减3元", "coupon_type": "配送费直减", ...},
    {"coupon_name": "晚餐配送8折", "coupon_type": "配送费折扣", ...}
]
results = generator.create_batch(
    batch_data=batch_data,
    project_name="全天时段配送优惠"
)
```

### Layer 3: 执行层 (Python脚本)

**核心执行引擎**:
- `scripts/delivery_coupon_generator.py` - 主生成器
- `scripts/parsers/coupon_parser.py` - 配送券需求解析
- `scripts/validators/rule_validator.py` - 规则验证器
- `scripts/validators/conflict_checker.py` - 配置冲突检测
- `scripts/generators/config_generator.py` - 配置文件生成器

**执行步骤**:

1. **Step 1: 需求解析与结构化**
   - 调用 `coupon_parser.py` 解析自然语言或结构化数据
   - 提取配送券类型、优惠规则、适用范围、时间限制等信息
   - 识别特殊配置需求(会员专享、新用户专属等)

2. **Step 2: 规则验证**
   - 调用 `rule_validator.py`
   - 验证优惠规则合理性:
     - 满额门槛 > 减免金额(防止倒挂)
     - 折扣比例在合理范围内(0.1-1.0)
     - 阶梯优惠层级逻辑正确
   - 验证时间配置有效性

3. **Step 3: 配置冲突检测**
   - 调用 `conflict_checker.py`
   - 检测同时段是否有冲突活动
   - 检测同类型优惠券是否会相互干扰
   - 生成冲突报告和建议

4. **Step 4: 配置参数生成**
   - 按照美团管家后台字段规范组织数据
   - 填充必填字段,智能推断可选字段
   - 格式化日期、时间、金额等数据
   - 生成后台填写指引

5. **Step 5: 输出配置文件**
   - 调用 `config_generator.py`
   - 生成JSON格式配置文件
   - 生成可视化配置清单(Markdown)
   - 保存到标准输出路径

REQUIRED_FIELDS = {

    }

### 规则合理性检查

**检查标准**:
- 满额门槛 ≥ 0
- 减免金额 ≥ 0 且 < 配送费上限
- 折扣比例在 0.1-1.0 之间
- 阶梯规则按金额递增,减免递增
- 有效期开始时间 < 结束时间
- 可用时段不能为空(当限定时段时)

### 配置冲突检测

**检测维度**:
- ✅ 时段冲突: 同时段是否有其他配送券
- ✅ 类型冲突: 同类型券是否会相互干扰
- ✅ 叠加冲突: 是否可与其他优惠券叠加
- ✅ 成本冲突: 多券叠加是否导致成本超预算

## 注意事项

### 1. 配送费倒挂风险

**问题**: 减免金额设置不当,可能导致配送费倒挂(用户实付为负数)

**建议**:
- 设置最高减免上限
- 满额门槛应覆盖平均订单配送费
- 定期分析配送券使用数据,调整参数

### 2. 活动时间冲突

**问题**: 多个配送券活动时间重叠,用户不知道使用哪个

**建议**:
- 使用配置冲突检测功能
- 不同时段使用不同配送券
- 明确券的叠加规则

### 3. 用户限制合理性

**问题**: 限制过严(每人限领1张)导致覆盖用户少,限制过松导致成本失控

**建议**:
- 新店开业: 每人限领1张,限用1次
- 日常运营: 每人限领3-5张,每天限用1-2次
- 会员权益: 不限领取,每月限用5-10次

### 4. 总发放量控制

**问题**: 总发放量设置不当,可能导致活动提前结束或成本超预算

**建议**:
- 根据预算倒推总发放量
- 设置每日限量,避免一天内发完
- 实时监控发放情况,动态调整

### 5. 批量处理性能

**问题**: 批量创建10+配送券时性能较慢

**建议**:
- 使用异步处理
- 分批执行(每批5个)
- 启用缓存机制
