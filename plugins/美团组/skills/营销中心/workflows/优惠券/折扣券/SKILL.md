# 折扣券创建技能包 (Discount Coupon Creator)

## 概述

这是一个**标准操作流程(SOP)型技能包**,用于自动化创建美团管家后台的折扣券活动。遵循**三层架构模式**,支持单个和批量创建,能够智能解析自然语言描述或结构化数据,生成标准化的配置方案和操作指引。

**折扣券**是一种按折扣比例优惠的营销工具,适用于:
- ✅ 新店引流 (如新店首单8折)
- ✅ 会员福利 (如会员专享9折)
- ✅ 节日促销 (如周年庆全场8.8折)
- ✅ 特定商品促销 (如指定菜品8折)

## 核心能力

### 1. 多源信息解析

**支持输入格式**:
- ✅ 自然语言描述 (中文/英文)
- ✅ 结构化数据 (JSON/YAML)
- ✅ 混合格式
- ✅ 批量数据文件 (Excel/CSV)

**智能提取能力**:
- 活动名称和描述
- 折扣比例 (如8折、9折)
- 最高优惠金额 (如最高优惠10元)
- 适用商品和范围
- 使用条件和限制
- 投放时间和渠道

### 2. 折扣券核心特性

#### 折扣规则配置

**折扣比例**:
- 支持范围: 0.1折 - 9.9折
- 推荐设置:
  - 大额促销: 5折 - 7折
  - 常规促销: 8折 - 9折
  - 会员专属: 8.8折、9.5折

**最高优惠金额**:
- 用途: 限制单笔订单最高优惠额度
- 示例:
  - 8折券 + 最高优惠10元 → 订单50元以上按10元优惠
  - 9折券 + 无限制 → 按实际折扣计算

**使用门槛**:
- 无门槛: 任意金额可用
- 满减门槛: 如满50元可用
- 推荐策略:
  - 新客引流: 无门槛或低门槛 (满30元)
  - 提升客单价: 高门槛 (满100元)

#### 适用范围配置

**商品范围**:
- 全部商品: 店内所有商品可用
- 指定分类: 如"火锅类"、"饮料类"
- 指定商品: 精确到具体SKU
- 排除商品: 指定不参与活动的商品

**适用渠道**:
- 美团外卖
- 美团堂食
- 美团团购
- 全渠道通用

**适用门店**:
- 单门店: 指定某一家门店
- 多门店: 选择多家门店
- 全部门店: 适用于所有门店

### 3. 配置方案生成

**基于美团管家后台规范**:
- 活动基本信息
- 折扣规则设置
- 适用范围配置
- 使用限制设置
- 投放渠道选择

**核心处理逻辑**:
1. **必填字段验证**: 活动名称、折扣比例、有效期等
2. **业务规则校验**: 折扣比例范围、时间冲突检测
3. **智能字段推断**: 根据输入信息自动填充可选字段
4. **配置方案输出**: 生成结构化JSON配置 + 操作步骤文档

## 快速开始

### 基础用法

```python
from scripts.discount_coupon_generator import DiscountCouponGenerator

# 初始化生成器
generator = DiscountCouponGenerator()

# 方式1: 自然语言输入
result = generator.create_from_text(
    text="""
    创建一个新客首单8折券:
    - 活动名称: 新客首单8折
    - 折扣比例: 8折
    - 最高优惠: 10元
    - 使用门槛: 满30元可用
    - 有效期: 2025-01-10 至 2025-01-31
    - 适用范围: 全部商品
    - 每人限领1张,每张限用1次
    """,
    project_name="新店开业营销活动"  # 项目名称(必填)
)

# 方式2: 结构化数据输入
data = {
    "activity_name": "会员专享9折券",
    "discount_rate": 0.9,  # 9折
    "max_discount_amount": 15,  # 最高优惠15元
    "min_order_amount": 50,  # 满50元可用
    "valid_period": {
        "start": "2025-01-15 00:00:00",
        "end": "2025-02-15 23:59:59"
    },
    "applicable_scope": {
        "type": "all_products",  # 全部商品
        "channels": ["meituan_takeout", "meituan_dinein"],
        "stores": "all"  # 全部门店
    },
    "usage_limits": {
        "per_user_limit": 1,  # 每人限领1张
        "per_coupon_limit": 1,  # 每张限用1次
        "daily_claim_limit": 100  # 每日发放上限
    }
}
result = generator.create_from_dict(
    data=data,
    project_name="会员日促销活动"
)

# 方式3: 批量创建
batch_data = [
    {
        "activity_name": "周末8折券",
        "discount_rate": 0.8,
        "valid_period": {...}
    },
    {
        "activity_name": "节日特惠9折券",
        "discount_rate": 0.9,
        "valid_period": {...}
    }
]
results = generator.create_batch(
    batch_data=batch_data,
    project_name="Q1营销活动批量配置"
)
```

## 创建流程 (美团管家后台操作步骤)

### Step 1: 进入优惠券管理

**操作路径**:
```
美团管家 → 营销中心 → 优惠券管理 → 创建优惠券 → 选择"折扣券"
```

### Step 2: 活动基本信息

**必填字段**:

| 字段名称 | 字段类型 | 说明 | 示例 |
|---------|---------|------|------|
| 活动名称 | 文本 | 优惠券展示名称,最多20字 | "新客首单8折" |
| 活动描述 | 文本 | 优惠券详细说明,最多50字 | "新用户首次下单立享8折优惠" |
| 优惠券类型 | 选择 | 固定选择"折扣券" | 折扣券 |
| 优惠券封面 | 图片 | 建议尺寸750x400px | 上传图片或使用默认模板 |

**可选字段**:

| 字段名称 | 字段类型 | 说明 | 示例 |
|---------|---------|------|------|
| 副标题 | 文本 | 补充说明,最多15字 | "限新用户" |
| 优惠券标签 | 选择 | 如"新人专享"、"会员专属" | 新人专享 |

### Step 3: 折扣规则设置

**核心配置**:

| 字段名称 | 字段类型 | 必填 | 说明 | 示例 |
|---------|---------|------|------|------|
| 折扣比例 | 数字 | ✅ | 范围0.1-9.9折 | 8折 (输入8) |
| 最高优惠金额 | 数字 | ❌ | 限制单笔最高优惠额 | 10元 |
| 使用门槛 | 选择+数字 | ✅ | "无门槛"或"满X元可用" | 满30元可用 |

**折扣计算规则**:
```
实际优惠金额 = MIN(订单金额 × (1 - 折扣比例), 最高优惠金额)

示例:
- 订单100元,8折券(最高优惠10元)
  → 优惠金额 = MIN(100×0.2, 10) = 10元
  → 实付 = 100 - 10 = 90元

- 订单40元,8折券(最高优惠10元)
  → 优惠金额 = MIN(40×0.2, 10) = 8元
  → 实付 = 40 - 8 = 32元
```

### Step 4: 适用范围配置

#### 4.1 商品范围

**配置项**:

| 选项 | 说明 | 适用场景 |
|-----|------|---------|
| 全部商品 | 店内所有商品可用 | 全场促销 |
| 指定分类 | 选择商品分类 | 分类促销(如"火锅类8折") |
| 指定商品 | 精确选择SKU | 单品促销(如"招牌菜8折") |
| 排除商品 | 排除不参与的商品 | 保护利润商品 |

**操作步骤**:
1. 选择商品范围类型
2. 如选择"指定分类/商品",点击"添加"按钮
3. 在弹窗中勾选目标分类或商品
4. 点击"确认"保存

#### 4.2 适用渠道

**可选渠道**:

| 渠道 | 说明 | 典型场景 |
|-----|------|---------|
| 美团外卖 | 仅外卖订单可用 | 提升外卖订单量 |
| 美团堂食 | 仅堂食订单可用 | 引流到店消费 |
| 美团团购 | 仅团购订单可用 | 团购活动配合 |
| 全渠道 | 所有渠道通用 | 全渠道促销 |

**多选支持**: 可同时勾选多个渠道

#### 4.3 适用门店

**配置方式**:

| 方式 | 说明 | 操作 |
|-----|------|------|
| 全部门店 | 所有门店适用 | 选择"全部门店" |
| 指定门店 | 选择特定门店 | 勾选目标门店 |
| 排除门店 | 排除某些门店 | 先选"全部",再排除 |

### Step 5: 使用限制设置

**用户限制**:

| 字段名称 | 字段类型 | 必填 | 说明 | 推荐值 |
|---------|---------|------|------|-------|
| 每人限领张数 | 数字 | ✅ | 单用户可领取数量 | 1-3张 |
| 每张限用次数 | 数字 | ✅ | 单张券可使用次数 | 1次 |
| 用户类型限制 | 选择 | ❌ | 如"新用户"、"老用户"、"全部用户" | 新用户 |

**时间限制**:

| 字段名称 | 字段类型 | 必填 | 说明 | 示例 |
|---------|---------|------|------|------|
| 领取时间 | 日期时间 | ✅ | 券的发放时间段 | 2025-01-10 00:00 至 2025-01-31 23:59 |
| 有效期类型 | 选择 | ✅ | "固定日期"或"领取后N天" | 固定日期 |
| 使用时间 | 日期时间 | ✅ | 券的可使用时间段 | 2025-01-10 00:00 至 2025-01-31 23:59 |
| 可用时段 | 时间段 | ❌ | 如"11:00-14:00, 17:00-21:00" | 全天可用 |

**发放限制**:

| 字段名称 | 字段类型 | 必填 | 说明 | 推荐值 |
|---------|---------|------|------|-------|
| 发放总量 | 数字 | ✅ | 优惠券总发放量 | 1000张 |
| 每日发放上限 | 数字 | ❌ | 控制每日发放量 | 100张/天 |
| 发放方式 | 选择 | ✅ | "用户主动领取"或"系统自动发放" | 用户主动领取 |

### Step 6: 其他配置项

**推广设置**:

| 字段名称 | 字段类型 | 说明 | 示例 |
|---------|---------|------|------|
| 券包投放 | 选择 | 是否加入券包 | 加入"新人专享券包" |
| 推送通知 | 开关 | 发券后是否推送通知 | 开启 |
| 分享设置 | 开关 | 是否允许用户分享 | 开启 |

**数据统计**:

| 字段名称 | 说明 |
|---------|------|
| 统计维度 | 领取量、使用量、核销率 |
| 报表查看 | 营销中心 → 优惠券报表 |

### Step 7: 预览与提交

**提交前检查清单**:

```
□ 活动名称清晰易懂
□ 折扣比例和最高优惠金额设置合理
□ 使用门槛符合营销目标
□ 适用商品范围已正确配置
□ 适用渠道和门店已正确选择
□ 使用限制(领取数、使用次数)已设置
□ 有效期时间段无冲突
□ 发放总量充足
□ 预览效果符合预期
```

**操作步骤**:
1. 点击"预览"按钮查看优惠券展示效果
2. 确认无误后点击"提交审核"
3. 等待平台审核通过(通常1-2小时)
4. 审核通过后,优惠券自动上线

## 注意事项

### 1. 折扣比例设置

**常见误区**:
- ❌ 折扣过大 (如3折): 可能导致亏损
- ❌ 折扣过小 (如9.9折): 吸引力不足
- ✅ 建议: 新客7-8折,老客8.5-9折

### 2. 最高优惠金额控制

**风险控制**:
- 未设置最高优惠: 大额订单可能导致成本失控
- 建议: 根据客单价设置合理上限
  - 客单价50元 → 最高优惠5-10元
  - 客单价100元 → 最高优惠10-20元

### 3. 使用门槛设置

**平衡策略**:
- 无门槛: 适合新客引流,但成本较高
- 低门槛 (满30-50元): 覆盖大部分订单
- 高门槛 (满100元+): 提升客单价,但覆盖率低

### 4. 有效期设置

**时间规划**:
- 领取时间 = 使用时间: 限时抢购,营造紧迫感
- 领取时间 < 使用时间: 提前领取,引导复购
- 避免设置过长有效期 (>3个月): 影响复购频率

### 5. 发放量控制

**成本管理**:
- 预估成本 = 发放总量 × 预计核销率 × 平均优惠金额
- 建议: 首次活动保守预估,根据数据调整
- 设置每日限额: 避免短期内成本集中爆发

### 6. 用户类型限制

**精准营销**:
- 新用户: 用于拉新,成本较高
- 老用户: 用于促活,提升复购
- 会员: 用于会员权益,增强粘性
- 建议: 根据营销目标精准设置
