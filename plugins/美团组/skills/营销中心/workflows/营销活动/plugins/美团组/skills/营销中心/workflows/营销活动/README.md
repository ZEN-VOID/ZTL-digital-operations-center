## 📝 使用说明

### 目录命名规范

- **分类目录**: 采用 `序号-分类名称` 格式 (如: `01-会员拉新`)
- **活动子目录**: 直接使用活动名称 (如: `开卡有礼`)

### 扩展指南

每个活动子目录可以包含以下内容:

```
活动名称/
├── README.md           # 活动说明文档
├── config.json         # 活动配置参数
├── workflow.md         # 操作流程指南
├── examples/           # 示例案例
└── templates/          # 模板文件
```

### 相关技能包

- **营销活动创建**: `plugins/美团组/skills/营销中心/workflows/营销活动创建/`
- **营销数据分析**: `plugins/美团组/skills/营销中心/workflows/营销数据分析/`
- **会员管理**: `plugins/美团组/skills/会员中心/`
